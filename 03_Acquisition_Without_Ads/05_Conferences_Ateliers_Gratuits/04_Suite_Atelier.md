# 04 — La suite de l'atelier (conversion sans pitch)

## Le principe

L'atelier sème ; la suite récolte. La conversion se fait en privé, jamais sur scène.

## J+0 (dans l'heure)
- Remercier les participants présents.
- Déposer le support PDF + le lead magnet dans le canal annoncé (email/landing).
- Noter les 3 questions restées sans réponse complète → sujets de contenu.

## J+1 à J+2 (24-48h)
- Envoyer le replay + support aux inscrits absents (« voici le replay »).
- Message sobre, sans offre : le diagnostic est mentionné une fois, pas martelé.

## J+7 (le message qui convertit)
```
Objet : Votre question sur [thème de l'atelier]

Bonjour [nom],
À l'atelier du [date], vous avez posé une question sur [sujet].
Le point clé : [1 phrase de mécanisme].
Si vous voulez vérifier votre situation précise, le diagnostic
de 45 min est le format adapté — [lien Calendly].
Bonne semaine,
```

## Mesure (J+7 / J+30)
| Indicateur | Cible indicative |
| :--- | :--- |
| Replay ouvert | 30-50 % des inscrits |
| Guide téléchargé | 10-20 % |
| Diagnostics réservés | 5-10 % |
| Missions signées | 2-5 % |

## Les 3 erreurs
1. Pitcher à la fin de la séance (tue la conversion).
2. Attendre « le bon moment » pour relancer (le bon moment = J+7).
3. Relancer sans contenu (une relance vide = un désabonnement).

## FAQ
**Q : Combien de relances après l'atelier ?**
R : Deux : le replay (J+1) et le message personnalisé (J+7). Au-delà, c'est du harcèlement.
