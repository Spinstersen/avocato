# 04 — Entretien du réseau et suivi des partenaires

## Le principe

Un partenaire non entretenu devient un contact mort. Le réseau se maintient avec un rythme, pas avec un contrat.

## Le rythme (par partenaire)

| Fréquence | Geste | Objectif |
| :--- | :--- | :--- |
| Mensuel | Message utile (texte, échéance, événement) | Rester présent sans demander |
| Trimestriel | Déjeuner/café de 45 min | Comprendre son portefeuille |
| Semestriel | Co-animation d'un atelier ou d'un webinaire | Autorité commune |
| Annuel | Bilan du partenariat (dossiers échangés) | Décider : continuer / ajuster |

## La liste de suivi (une ligne par partenaire)

| Partenaire | Type | Contact | Dernier échange | Dossiers reçus | Dossiers renvoyés | Prochaine action | Date |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| | | | | | | | |

## Les 4 règles d'entretien
1. **Donner avant de demander** : envoyer une information utile avant toute requête.
2. **Réciprocité visible** : orienter des clients vers le comptable (2 reçus = 1 renvoyé minimum).
3. **Aucune commission** : jamais d'argent, jamais de pay-per-lead (art. 30 loi 28-08 + RIO).
4. **Traçabilité** : chaque échange/dossier dans la ligne de suivi — le réseau se pilote comme un pipeline.

## Le message mensuel type (WhatsApp/email)
> « Bonjour [nom], deux échéances à retenir ce mois-ci : [obligation 1, date], [obligation 2, date]. Si un de vos clients a une question là-dessus, je suis disponible. Bonne semaine. »

## Quand un partenaire se refroidit
- 2 relances espacées sans réponse → passer en « dormant » (relance trimestrielle seulement).
- 0 dossier échangé sur 12 mois → réunion de bilan honnête : périmètre différent ou relation qui s'arrête.

## FAQ
**Q : Faut-il un contrat de partenariat écrit ?**
R : Non. Une lettre d'engagement moral suffit ; le contrat formalisé est inutile et alourdit.

**Q : Combien de partenaires entretenir en solo ?**
R : 5-10 actifs maximum. Au-delà, la qualité d'entretien chute.
