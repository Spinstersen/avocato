# 01 — Identification des partenaires pertinents

## Types de partenaires

| Type | Pertinence | Raison |
| :--- | :--- | :--- |
| Comptables / experts-comptables | Excellente | PME en portefeuille, connaissent les besoins juridiques |
| Fiduciaires | Excellente | Même profil |
| Consultants gestion/RH/IT | Bonne | Besoins juridiques adjacents |
| Incubateurs / accélérateurs | Bonne | Startups en croissance |
| Notaires | Bonne | Co-intervention sur cessions |
| Huissiers | Moyenne | Utiles pour contentieux |
| Traducteurs assermentés | Moyenne | Complémentaires trilingue |
| Avocats étrangers | Excellente | Dossiers transfrontières |
| Banques pro | Moyenne | Orientent les créateurs |

## Méthode

1. Lister 20 partenaires potentiels dans votre région.
2. Identifier les 10 plus pertinents.
3. Trier par ordre de priorité.
4. Contacter 1 par semaine.
