# 04 — Mesurer le moteur de recommandation

## Pourquoi mesurer

Un referral non mesuré se confond avec la chance. On mesure le taux, la source et le délai.

## Les 5 chiffres
| Indicateur | Formule | Cible indicative |
| :--- | :--- | :--- |
| Demandes faites | nombre de referrals demandés | 1 par client livré |
| Taux de réponse | filleuls reçus / demandes | 20-40 % |
| Taux de conversion | missions signées / filleuls | 20-30 % |
| Délai moyen | jours entre demande et signature | 15-45 j |
| Part du CA | CA referral / CA total | 20-40 % (après 12 mois) |

## Le registre (une ligne par demande)
| Date | Client source | Demandé par | Filleul | Statut | Signé le | Mission | CA |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| | | | | | | | |

## Lecture des chiffres
- **Taux de réponse faible (<10 %)** : mauvais moment (demandé trop tôt ou trop tard) ou demande non personnalisée.
- **Conversion faible** : le filleul est mal qualifié (mauvais profil de niche).
- **Délai long** : relancer le filleul à J+7 puis archiver, sans pression.

## Où le suivi vit
- Notion (base Clients : champ « recommandé par »).
- Revue mensuelle du KPI tracker (`07_90Day_Plan/06_Templates_KPI_Tracker.md`).
- Le referral est un canal, pas un accident : 1 client livré = 1 demande.

## FAQ
**Q : Comment savoir si le client a vraiment recommandé ?**
R : On demande au filleul « comment m'avez-vous connu ? » et on note la source dans le dossier.

**Q : Faut-il récompenser chaque recommandation ?**
R : Non — pas de commission (interdit). La récompense de courtoisie est décrite en `03_La_Recompense.md`.
