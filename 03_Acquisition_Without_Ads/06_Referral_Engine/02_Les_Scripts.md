# 02 — Les scripts de demande de referral

## 1. Version email (J+3)

```
Bonjour [nom],

J'espère que la mission [type] vous convient. Si vous avez
2 minutes, je vous serais reconnaissant de me dire ce qui
vous a plu le plus. Cela m'aide à améliorer mon offre.

Par ailleurs, si vous connaissez 1-2 autres [freelances/
e-commerçants/PME] qui ont le même type de problème, je
peux leur envoyer la même checklist gratuitement. Vous me
mettez en contact WhatsApp ou par email ?

Pour chaque recommandation, j'offre un diagnostic gratuit
(valeur 600-900 DH HT) au filleul.

Bien à vous,
[Nom]
```

## 2. Version WhatsApp (J+5)

```
Bonjour [nom], j'espère que tout va bien. Suite à la
mission, si vous connaissez d'autres [freelances] dans votre
réseau qui pourraient avoir besoin de sécuriser leurs
contrats offshore, je propose un diagnostic gratuit au
filleul. Vous pouvez me mettre en contact par WhatsApp.
```

## 3. Version orale (visio de clôture)

```
Content que la mission vous convienne. Si vous connaissez
d'autres [freelances] qui sont dans la même situation,
n'hésitez pas à me mettre en contact. Je leur offre un
diagnostic gratuit.
```

## 4. La règle

> Pas de pression. Pas de commission. Diagnostic gratuit offert au filleul.

## FAQ

**Q : Le filleul est-il informé de qui l'a recommandé ?**
R : Oui, mentionner le nom du client recommandant.
