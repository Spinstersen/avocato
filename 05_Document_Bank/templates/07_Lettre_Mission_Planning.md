# Modèle : Lettre de mission & Planning (1 page, joint à la convention)

```
LETTRE DE MISSION — Planning prévisionnel

Dossier : [Nom / Société] — Convention CH-2025-[015] — Mission [X]
Responsable : Me [Nom] — Collaborateur : [si applicable]

Étapes :
J0   Signature + provision [50%] + réception pièces (checklist ci-dessous)
J+1  Recherche / audit documentaire
J+2  Rédaction V1 + contrôle qualité interne
J+3  Envoi V1 (PDF) + Loom 15 min + recueil observations (48h)
J+5  V1 corrigée (1 révision incluse) + facturation solde + envoi final Word+PDF

Pièces à fournir par le Client (cocher) :
[ ] CIN / Passeport gérant(s)
[ ] ICE / RC / Statuts existants
[ ] Contrats / CGV actuels
[ ] Autres : [préciser]

Canal : WhatsApp [numéro] + Email [x@.ma] — Réponse sous 24h ouvrées
Livrables : [lister]

Fait à [Ville], le [Date]
```

**Usage :** Joint à la convention. Donne un cadre professionnel, rassure, évite les "où en est mon dossier ?".
