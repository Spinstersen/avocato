# Skills #4: Design with Canva (Your Unfair Advantage)

> Most lawyers' documents look like 1998 Word. Yours will look like Apple. Clients pay 30% more for same content if it looks premium.

## Brand Kit (Set Once, 15 min)

In Canva → Brand Kit:
- **Primary:** Navy #0F2A44 (confiance)
- **Secondary:** Beige #F5F1E8 (papier)
- **Accent:** Teal #1FA89E (moderne)
- **Text:** Dark #1A1A1A
- **Fonts:** Titles: General Sans / Inter Bold ; Body: Inter Regular ; Arabic: IBM Plex Sans Arabic
- **Logo:** Simple text: `Me [NOM] — Avocat d'Affaires` (no clipart)

Use same kit for EVERYTHING: devis, contracts, carousels, affiche.

## 4 Templates to Create This Week

### 1. Carousel LinkedIn (1080x1350px)
- Slide 1: Hook big + number
- Slides 2-6: Icon top + Title + 2 lines + footer page number
- Slide 7: CTA "Checklist en commentaire" + QR
Save as PDF.

### 2. Contract / CGV Template (A4)
- Cover page: Logo + Title "Contrat de Prestation" + Client / Date + version number
- Table of contents auto
- Headers: Article 1, 2 with teal line
- Footer: Page X/Y + "Confidentiel — Me [Nom]"
- Last page: Signatures with lines + "Lu et approuvé"
Clients will think "Wow, this is not a Word copy-paste".

### 3. Devis / Facture (A4)
- Header with logo + ICE/IF
- Table: Désignation | Qté | Prix
- Conditions: "50% à la commande, 50% à la livraison. Vallable 7 jours."
- Button style footer: "Accepter via WhatsApp: [numéro]"

### 4. Affiche Atelier (A5) + Checklist 1-page (A4)
- Affiche: Title big + Date/Lieu + 3 bullets value + "Gratuit - 20 places - Inscription WhatsApp [QR]"
- Checklist: Title + 12 checkboxes with icons + footer contact.

## Where to Find Icons
- Canva → Elements → "line icon" (minimal, not 3D)
- Use same style everywhere.

## Workflow (ADHD)
- Don't design from scratch each time. Duplicate template → change text → export.
- Batch: Sunday 11am, create 3 carousels at once (music + timer 25 min each).
- Save all in Canva folder "AVOCATO".

## Free Resources
- Canva Pro: Ask for free Pro via Canva for Education if you have master email, or 30-day trial.
- Alternative: Figma (free) if you love design more.
