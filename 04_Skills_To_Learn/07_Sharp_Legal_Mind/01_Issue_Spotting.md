# 01 — Issue-spotting : méthode et exercices

## 1. La méthode

### Étape 1 — Écouter les faits (5-10 min)

Laisser le prospect parler sans interruption. Prendre des notes. Ne pas poser de question juridique encore.

### Étape 2 — Identifier les catégories juridiques

Pour chaque situation, vérifier :

1. **Statut** (AE, SARL, autre)
2. **Contrats** (existence, conformité)
3. **Fiscalité** (TVA, IR, IS, conventions bilatérales)
4. **Social** (salariat, freelances, CNSS)
5. **Conformité numérique** (Loi 09-08, Loi 31-08)
6. **Propriété intellectuelle** (droit d'auteur, marques)
7. **Contentieux** (litiges en cours ou potentiels)

### Étape 3 — Formuler les questions juridiques

Pour chaque catégorie pertinente, formuler la question juridique :

- Le statut AE est-il dépassé par le CA ?
- Les contrats clients sont-ils conformes ?
- La TVA sur les prestations offshore est-elle exonérée ?
- Les mentions 09-08 sont-elles conformes sur le site ?
- La clause IP du contrat est-elle protectrice ?

### Étape 4 — Évaluer les risques

Pour chaque question, évaluer :

- **Gravité** (haute/moyenne/basse).
- **Probabilité** (haute/moyenne/basse).
- **Coût estimé** si non résolu (montant en DH).

### Étape 5 — Hiérarchiser

Trier les risques par gravité × probabilité, du plus urgent au moins urgent.

### Étape 6 — Proposer des actions

Pour chaque risque identifié :

- Action recommandée (mission, audit, mise à jour).
- Honoraire indicatif.
- Délai.

## 2. L'arbre d'issue-spotting

```
[Prospect expose sa situation (5-10 min)]
```

## 3. Les 7 catégories juridiques — checklist

### Statut
- [ ] Quel statut juridique ?
- [ ] CA annuel ?
- [ ] Plafond atteint ?
- [ ] Besoin de changement ?

### Contrats
- [ ] Contrats clients existants ?
- [ ] Contrats conformes ?
- [ ] Clauses essentielles présentes (paiement, IP, résiliation, juridiction) ?
- [ ] Contrats FR/EN pour offshore ?

### Fiscalité
- [ ] Régime fiscal actuel ?
- [ ] TVA exonérée si offshore (art. 92 CGI) ?
- [ ] IR ou IS ?
- [ ] Convention fiscale bilatérale applicable ?

### Social
- [ ] Salariés ?
- [ ] Freelances ?
- [ ] CNSS à jour ?

### Conformité numérique
- [ ] Site web avec mentions 09-08 ?
- [ ] Bannière cookies conforme ?
- [ ] Politique de confidentialité ?
- [ ] Registre 09-08 tenu ?

### Propriété intellectuelle
- [ ] Clause IP dans les contrats ?
- [ ] Marques déposées ?
- [ ] Droit d'auteur respecté ?

### Contentieux
- [ ] Litiges en cours ?
- [ ] Litiges potentiels ?
- [ ] Procédures disciplinaires ?

## 4. Le cas pratique-type — issue-spotting pour un freelance dev offshore

### Faits écoutés

Yassine, 28 ans, freelance dev full-stack à Casablanca. AE avec 60 k EUR/an CA (env. 600 k DH/an). Clients en France, UK, US. Paiements via Payoneer. Pas de contrat type, factures non conformes, Stripe bloqué.

### Catégories vérifiées

1. **Statut** : AE avec CA 600 k DH/an → **plafond 200 k DH dépassé depuis 3 ans**. Risque : redressement fiscal. Gravité haute.
2. **Contrats** : aucun contrat type. Risque : litige client sans protection. Gravité haute.
3. **Fiscalité** : TVA non déclarée (alors qu'il aurait dû être exonéré art. 92). Risque : régularisation avec pénalités. Gravité moyenne.
4. **Social** : pas de salarié. OK.
5. **Conformité numérique** : pas concerné (pas de site web marchand).
6. **Propriété intellectuelle** : clause IP absente. Risque : perte de droits sur le code. Gravité haute.
7. **Contentieux** : pas de litige en cours. Stripe bloqué = litige potentiel avec Stripe.

### Hiérarchisation

1. Statut dépassé (gravité haute, probabilité haute).
2. Contrat absent (gravité haute, probabilité haute).
3. IP non cédée (gravité haute, probabilité moyenne).
4. TVA non déclarée (gravité moyenne, probabilité haute).
5. Stripe bloqué (gravité moyenne, probabilité haute).

### Actions proposées

1. Création SARL-AU (4 900 DH HT).
2. Pack Freelance Contrat Offshore (2 900 DH HT).
3. Pack Stripe Offshore Structuration (6 900 DH HT).
4. Régularisation TVA (mission comptable avec comptable partenaire).

Total : 14 700 DH HT + régularisation TVA.

## 5. FAQ

R : 6-12 mois de pratique active (5-10 diagnostics/mois).

**Q : Faut-il formaliser l'issue-spotting dans un document ?**
R : Oui, la note de risques écrite est le livrable du diagnostic.
