# 01 — Prompts type pour avocat

## 1. Prompt pour générer un post LinkedIn

```
Tu es un avocat d'affaires trilingue au Maroc, spécialisé en
[freelance offshore / e-commerce / conformité 09-08].

Rédige un post LinkedIn long form (200-400 mots) sur le sujet
suivant : [sujet précis].

Format :
- Ton analytique, pas promotionnel.
- Pas de comparaison avec un confrère.
- Pas de CTA commercial.
- Pas de promesse de résultat.
- Signature sobre à la fin.
```

## 2. Prompt pour résumer une jurisprudence

```
Tu es un assistant juridique. Résume la jurisprudence
suivante en 200 mots maximum, en identifiant :
1. Les faits
2. La question de droit
3. La décision
4. La portée pour la pratique

Texte à résumer : [texte intégral]
```

## 3. Prompt pour reformuler un article

```
Reformule l'article suivant dans un style plus lisible et
engageant, sans perdre la précision juridique. Garde les
références aux articles de loi. Structure avec des titres H2.

Article : [texte]
```

## 4. Prompt pour générer un carrousel Canva

```
Transforme l'article suivant en un carrousel Canva de 8 slides
(format 1080×1080).

Structure :
- Slide 1 : Titre accrocheur
- Slides 2-7 : Points clés (1 idée par slide)
- Slide 8 : Call-to-action sobre (lien site)

Article : [texte]
```

## 5. Prompt pour générer une checklist

```
Crée une checklist de [X points] sur le sujet suivant :
[sujet précis]. Format : liste à cocher. Ton : pratique,
accessible. Pas de jargon.

Inclure des références juridiques (articles de loi, arrêts).
```

## 6. Prompt pour anonymiser un cas pratique

```
Anonymise la situation suivante pour la rendrepubliable
sur LinkedIn sans identification possible du client.
Remplace les noms, montants, dates identifiables.

Situation : [description]
```

## 7. Prompt pour identifier les risques juridiques

```
Tu es un avocat d'affaires marocain. Analyse la situation
suivante et identifie les 3-5 risques juridiques principaux.

Pour chaque risque :
- Gravité (haute/moyenne/basse)
- Coût estimé si non résolu
- Référence juridique

Situation : [description]
```
