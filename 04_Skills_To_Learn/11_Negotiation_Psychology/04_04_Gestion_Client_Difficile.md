# 04 — Gestion Client Difficile : 4 profils qui bloquent 2900 (et script 90s)

## Définition
Client difficile = **4 profils qui font dérailler négo 2900/5900** : Le Négociateur (veut -50%), L'Indécis ("je réfléchis" 3 semaines), L'Aggressif ("300k c'est faux"), Le Ghost (disparaît après devis). Sans script, 40 min perdues/client → 0 clos. Avec script 90s/profile → 8 min max → clos ou no deal clair. Objectif : 70% désamorcés, 30% no deal BATNA (01).

## Framework complet — 4 profils + script 90s Voss

| Profil | Phrase type | Fear caché | Script 90s (Voss + art + CTA) |
|---|---|---|---|
| **Négociateur** | "2900 trop, 1500 ?" | Veut gagner | Miroir "1500 ?" + étiquette "Il semble que 1500 soit max ?" + ancre 5900 + BATNA 725/h → "2900 mini ou gratuit seul" |
| **Indécis** | "Je réfléchis, je reviens" | Peur 300k vs prix | "Vous réfléchissez ?" (4s) + "Qu'est-ce qui vous empêche 2900 aujourd'hui ?" + rareté "2 places cette semaine" |
| **Aggressif** | "09-08 bullshit, 80 mails pas concerné" | Déni | "80 mails ?" + art.14 dès 1 mail + CNDP 2023-045 30k pour 80 mails → preuve 45j |
| **Ghost** | Silence J+3 après devis | Comparaison agence 5000 | J+3 mail 60 mots + 09-08 droit opposition + CTA Calendly 15 min |

**3 piliers :** Voss 03 + art exact sgg + BATNA 01.

## Procédure pas-à-pas chiffrée (8 min / client difficile)

1. **09h00 identifie profil (30s)** : Calendly + mail → tag profil. Négociateur = chiffre 1500 direct, Indécis = "je réfléchis", Aggressif = "faux", Ghost = silence J+3.
2. **Miroir+étiquette 30s** : Ex Négociateur 1500 → "1500 ?" (4s) → "Il semble que 1500 soit le max vs 2900 ?" → silence → il donne BATNA (agence 5000 / modèle gratuit).
3. **Preuve 45s** : Art exact + chiffre choc. Aggressif 80 mails → "Art.14 dès 1 mail, CNDP 2023-045 sanction 30k pour 80 mails, art.52 10k-300k + publication. Registre 5 col =5 min J1." Pas d'opinion, art.
4. **CTA soft 90s** : "On peut faire 2900 avec registre+déclaration, ou 5900 avec politique+dépôt. Si 1500, je retire dépôt (vous déposez seul, je guide 10 min). On bloque 2900 ou on se rappelle quand budget ?" Décision binaire (09_09).
5. **Ghost J+3 (2 min)** : Template Brevo 60 mots : "Fatima, silence depuis devis 2900. Il semble que agence 5000 vs 2900 vous fasse hésiter ? 300k vs 2900=1%. Je vous retire si pas concernée (09-08 opposition) → répondez STOP. Sinon 15 min ? [Calendly]" → 40% reviennent.
6. **Log + no deal (1 min)** : Si refuse <2900 → tag No Deal BATNA → modèle gratuit + reviens quand 2900. Temps sauvé 32 min vs 40 min débat.

## Erreurs Top 3

1. **Débattre 20 min avec Aggressif** → tu perds + NPS salle si atelier → corriger : 90s preuve art + CTA soft → no deal si persiste.
2. **Relancer Ghost 5×** → harcèlement 09-08 → corriger : 1 mail J+3 60 mots + STOP, pas 5 relances.
3. **Céder 1500 au Négociateur** → BATNA cassée (725/h → 375/h) → corriger : jamais sous 2900, concession = retire service (dépôt), pas baisse.
