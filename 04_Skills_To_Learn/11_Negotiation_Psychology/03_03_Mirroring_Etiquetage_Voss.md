# 03 — Mirroring & Étiquetage Voss : faire parler 3× plus en disant 3 mots

## Définition
**Mirroring** = répéter 3 derniers mots du client avec intonation montante + silence 4s → il développe 3× plus. **Étiquetage** = "Il semble que vous..." / "On dirait que vous craignez..." → il se sent compris → défenses -60%. Sans Voss, client dit "c'est cher" → tu justifies 5 min → débat. Avec Voss, "cher ?" + silence → il dit budget réel → tu sais ZOPA.

## Framework complet — 2 outils + 5 phrases types avocat

| Outil | Formule | Quand | Exemple |
|---|---|---|---|
| **Miroir** | 3 derniers mots + ↗ + 4s silence | Après chaque objection | "2900 cher" → "Cher ?" (4s) |
| **Étiquette** | "Il semble que vous..." / "On dirait..." | Après miroir, il a parlé | "Il semble que 300k vous inquiète ?" |

**5 phrases types Maroc 2025 :**
1. "1500 max ?" → Miroir "1500 max ?" (4s) → Étiquette "Il semble que budget soit bloqué à 1500 ?"
2. "Je vais voir agence 5000" → "Agence 5000 ?" → "On dirait que vous hésitez entre 2900 et 5000 ?"
3. "09-08 pas pour moi 80 mails" → "80 mails ?" → "Il semble que vous pensiez petit = exempt ?"
4. "Shopify gère" → "Shopify gère ?" → "Il semble que vous craigniez de ne pas pouvoir changer ?"
5. "Je réfléchis" → "Vous réfléchissez ?" → "On dirait que quelque chose vous retient ?"

## Procédure pas-à-pas chiffrée (call 15 min)

1. **Prépare 5 miroirs (5 min avant call)** : Note 5 objections probables (1500, agence 5000, 80 mails, Shopify, "je réfléchis") + miroir 3 mots pour chaque. Imprime.
2. **0'-5' écoute + miroir 1 (30s)** : Client "Je pensais 1500 pour contrat freelance" → Toi "1500 pour contrat ?" (3 mots, ↗) → **silence 4s** (compte 1001-1004) → il dit "Oui 1500 car AE pas gros CA" → tu as info budget + peur.
3. **Étiquette 1 (15s)** : "Il semble que 1500 soit le max pour AE 200k ?" → il "Oui exact, plafond 200k" → tu sais ticket 12k si AE→SARL (glossaire §09) → upsell.
4. **5'-10' miroir 2 + étiquette 2 (45s)** : "Je vais comparer agence 5000" → "Agence 5000 ?" (4s) → "1200 vs 5000 ?" → Étiquette "On dirait que vous hésitez entre payer 5000 agence vs 2900 modèle + 300k risque ?" → silence → il choisit 2900.
5. **10'-15' close Voss (2 min)** : S'il dit "Je réfléchis" → Miroir "Vous réfléchissez ?" (4s) → Étiquette "On dirait que 2900 vs 300k vous fait hésiter ?" → "Qu'est-ce qui vous empêche de décider 2900 aujourd'hui ?" → question calibrée → il dit freins → tu résous 1 frein → clos.
6. **Post-call log (2 min)** : Note miroir→réponse→étiquette→clos. Compte silences 4s respectés (objectif 3/call).

## Erreurs Top 3

1. **Miroir 8 mots au lieu de 3** → "Vous voulez dire que 1500 est votre maximum pour ce contrat ?" → pas miroir → corriger : 3 mots max + ↗ + 4s.
2. **Pas de silence 4s → tu combles** → tu parles 60% → Voss échoue → corriger : compte 1001-1004 mental, ferme bouche.
3. **Étiquette accusatrice "Vous avez tort"** → défiance → corriger : "Il semble que..." (hypothèse douce, il corrige si faux → info).
