# 06 — Comparatif Harvard PON : position vs intérêt (gagner sans écraser)

## Définition
Harvard PON (Fisher/Ury) = **négocier sur intérêts (pourquoi) pas positions (combien)**. Position = "Je veux 1500". Intérêt = "Je veux être conforme sans payer 300k avec petit CA 30k". Sans Harvard, duel 1500 vs 2900 → blocage. Avec Harvard, tu trouves intérêt commun : "conforme 7j + petit budget" → 2900 avec dépôt retiré (tu guides 10 min, elle dépose) → deal.

## Framework complet — 4 principes Harvard + tableau positions/intérêts

|---|---|---|---|

## Procédure pas-à-pas chiffrée (call 15 min Harvard)

1. **0'-3' intérêts (Voss 03) 3 min** : "Vous dites 1500 ?" (miroir 4s) → "Il semble que budget 1500 soit lié à CA 30k + peur 300k ?" → il développe 3 intérêts : CA 30k, peur 300k, Shopify US. Note 3 intérêts.
2. **3'-6' personne/problème (2 min)** : "Je comprends CA 30k, c'est serré. Le problème n'est pas vous, c'est art.14 dès 1 mail → 30k pour 80 mails. On résout problème ensemble, pas vous vs moi." Sépare.
3. **6'-10' options 3 (3 min)** : "3 options objectif : 1) Gratuit modèle seul (vous déposez seul, risque 30% erreur), 2) 2900 (je vous guide 10 min dépôt CNDP, registre 5 col), 3) 5900 (je dépose 30j + politique). Critère objectif : art.52 300k, BATNA 725/h. Laquelle sert vos 3 intérêts ?"
4. **10'-13' critère objectif (2 min)** : "Art.52 10k-300k, CNDP 2023-045 30k pour 80 mails, art.14 5 col obligatoire. 2900 =1% sanction, 725/h BATNA SEO. C'est le critère, pas mon prix." Pas d'opinion, art + chiffre.
5. **13'-15' close win-win (2 min)** : "Si on fait 2900 sans dépôt CNDP (vous déposez, je corrige), vous économisez 3000 vs 5900 + conforme 7j. Provision 50% art.30 → 1450 aujourd'hui. On part là-dessus ?" Win-win.
6. **Log (1 min)** : Note intérêts 3 + option choisie + critère art.

## Erreurs Top 3

1. **Défendre position 2900 "je vaux 2900"** → duel → no deal → corriger : creuse intérêts 3 min Voss avant prix.
2. **1 option 2900 seule** → pas de win-win → corriger : toujours 3 options (gratuit/2900/5900) → il choisit milieu 2900.
3. **Critère subjectif "mon expérience 12 ans"** → non objectif → corriger : critère = art.14 + 2023-045 30k + BATNA 725/h (chiffre).
