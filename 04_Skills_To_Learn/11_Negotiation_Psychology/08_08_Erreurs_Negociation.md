# 08 — Erreurs Négociation : 5 pièges qui font perdre 1400 DH par deal

## Définition
Erreur négo = **faute qui fait passer deal 2900 → 1500 ou no deal**. Coût : 4 deals/mois ×1400 perte =5600/mois =67k/an. 5 erreurs =87% des pertes négo avocat Maroc (log 23 deals 2024). Chaque erreur = fix 48h + checklist.

## Framework complet — 5 erreurs + matrice

| # | Erreur | Symptôme | Perte | Fix 48h |
|---|---|---|---|---|
| 1 | Pas de BATNA | Accepte 1500 par peur vide | -1400 | BATNA 725/h (01) 5 min pré-call |
| 2 | Ancre basse 2900 | Négocie 1500-1800 | -1100 | Ancre 5900→2900 + 4s (02) |
| 3 | Parle 70% | Client 30% → pas d'info ZOPA | No deal | Voss miroir 3 mots + 4s 70% client parle (03) |
| 4 | 1 prix 2900 | Pas de comparatif → cher | -3000 upsell | Duo 2900/5900 (05) |
| 5 | Pas de provision 50% | Impayé 60% | -2900 | Convention art.30 + provision J0 (glossaire §10) |

**3 piliers anti-erreur :** BATNA chiffrée + Voss 70% écoute + 2 prix 2900/5900.

## Procédure pas-à-pas chiffrée — Audit 10 min / deal perdu

1. **Log deal perdu (2 min J0)** : Notion "Erreurs Négo" : client / offre 1500 / prix final / perdu -1400 / erreur # suspectée.
2. **Check BATNA (2 min)** : Avais-tu BATNA 725/h calculée avant call ? Si non → erreur 1. Fix : calcule BATNA 5 min pré-call (01).
3. **Check ancre (2 min)** : As-tu dit 5900 d'abord + silence 4s ? Si 2900 d'abord → erreur 2. Fix : script 5900→2900 (02).
4. **Check Voss (2 min)** : Replay call (si Loom) → qui parle 70% ? Si toi 70% → erreur 3. Fix : miroir 3 mots + 4s (03).
5. **Check prix (1 min)** : 1 prix ou 2 ? Si 1 → erreur 4. Fix : duo 2900/5900 + étalé 5000 (07).
6. **Check provision (1 min)** : Convention art.30 + 50% J0 ? Si non → erreur 5 → impayé. Fix : Yousign 50% avant J7.
