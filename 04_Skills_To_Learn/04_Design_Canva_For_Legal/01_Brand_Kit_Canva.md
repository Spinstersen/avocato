# 01 — Brand Kit Canva : configuration

## 1. Création du Brand Kit

### Étape 1 — Créer un compte Canva Pro

- Canva Pro : 12 USD/mois ou 120 USD/an.
- Compte professionnel avec email `nom@cabinet.ma`.

### Étape 2 — Configurer le Brand Kit

Dans Canva : **Brand** > **Brand Kit**.

- **Logo** : wordmark du cabinet (PNG transparent).
- **Palette** :
  - Primaire : `#0F2A44` (Navy).
  - Secondaire : `#F5F1E8` (Beige).
  - Accent : `#1FA89E` (Teal).
  - Gris clair : `#E5E5E5`.
  - Gris foncé : `#333333`.
- **Typographies** :
  - Titres : Inter Bold.
  - Corps : Inter Regular.
- **Images** : photos cabinet sobre (à éviter : stock cliché).

## 2. Les templates à créer

### Template 1 — Convention d'honoraires

- Format A4 portrait.
- Header : wordmark.
- Structure : parties, objet, honoraires, provision, conditions.
- Footer : mentions légales, n° de page.

### Template 2 — Plaquette cabinet

- Format A4 paysage.
- Couverture : titre + wordmark.
- Sections : cabinet, domaines, missions, contact.

### Template 3 — Carrousel LinkedIn (1080×1080)

- 8 slides.
- Palette + typographie du cabinet.
- Pas de clichés.

### Template 4 — Miniature YouTube (1280×720)

- Titre accrocheur.
- Palette du cabinet.
- Pas de visage outrancier, pas de flèches rouges.

### Template 5 — Visuels posts LinkedIn (1200×627)

- Citations, schémas, infographies.
- Palette + typographie.

## 3. La bibliothèque de visuels

- Photos : Unsplash (sélection stricte), Pexels (idem).
- Pas de banque Canva par défaut (clichés).
- Préférer visuels abstraits (formes, typographies).
- Éviter : balance de la justice, marteau, toge, cour d'assises.

## 4. Le système de nommage

- Convention d'honoraires : `CH-2025-XXX-Convention.pdf`.
- Plaquette cabinet : `Plaquette_Cabinet_2025.pdf`.
- Carrousel LinkedIn : `Carousel_[sujet]_[date].pdf`.
- Miniature YouTube : `Miniature_[sujet]_[date].png`.

## 5. La cohérence

Tous les supports doivent partager :
- Même palette.
- Même typographie.
- Même wordmark.
- Même structure visuelle.

> La cohérence construit l'identité de marque.
