# 11 — Veille mensuelle IGOC/CNDP/LF alimentant les 14-18 (protocole récurrent)

> La veille qui empêche les 14-18 de périmer. 2h/mois, 1 page, datée. Vérifié 07/09/2026 — sources : oc.gov.ma (IGOC + communiqués), cndp.ma (délibérations/guides), sgg.gov.ma / tax.gov.ma (LF/CGI/LPF), ompic.ma (bulletin/taxes), impots.gouv.fr/BOFiP (doctrine conventions FR).

## 1. Ordre de lecture mensuel (30 min par source)

IGOC/Office (nouvelle édition ? circulaire ADII ? dotations/rapatriement modifiés ? → MAJ `09/14-15`, `02/15`, `08/14`) → CNDP (guide/sanction/prospection ? → MAJ `03/14-16`, `02/14`) → LF/CGI (taux IS/RAS/TVA/AE ? → MAJ `08/14`, `06/15`, `08/00_INDEX`) → OMPIC (taxes/délais/classes ? → MAJ `07/14-16`) → conventions (nouvelle convention/protocole/MLI ? → MAJ `08/05`, `08/14`) → séjour/étrangers (02-03/décret ? → MAJ `11/14`).
## 2. Livrable 1 page (modèle)

Date + sources ouvertes (URL + édition) → ce qui change (3 lignes max par matière) → fichiers impactés (liste 14-18) → action (MAJ faite / à faire, dossier client à rappeler) → revue abonnés (e-mail 5 lignes aux packs veille : 09-08 4 500/mois, change, IP).
## 3. Règle d'or

Aucun chiffre 14-18 cité sans millésime (IGOC 202X, LF 202X, barème OMPIC du jour). Tout avis porte « vérifié le ___ sur ___ ». La veille est le seul abonnement qui protège tous les autres.
