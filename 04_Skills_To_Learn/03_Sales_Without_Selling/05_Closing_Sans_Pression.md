# 05 — Closing Sans Pression (5 min)

## Séquence

1. **Résumer risques:** "On a vu 3 risques: plafond AE (H), contrat (H), IP (M)"
2. **Présenter 2 options** (tableau 1 slide Notion/Canva)
3. **Demander préférence, pas engagement:** "Laquelle vous parle le plus?"
4. **Proposer next step doux:** "Je vous envoie convention Yousign demain, vous signez quand prêt sous 7j"
5. **Silence + note:** "Vous recevrez note risques 24h"

## Phrases closing

- "Pas besoin de décider maintenant"
- "Prenez 48h, je reste dispo"
- "Si vous dites non, aucun souci, la note vous reste utile"

## Après diagnostic (24h)

- Email: note 1 page + 2 conventions (Essentielle/Étendue) + Loom 3 min récap + lien Yousign
- Pas de relance avant J3.

## Taux cible

40-50% closing si SPIN bien exécuté, 20% si pitch. Mesurer in `07_Metriques`.
