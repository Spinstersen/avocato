# 02 — Script Diagnostic 40 min Verbatim

## Structure

```
0-5  Accueil + cadre ("40 min, pas de vente, diagnostic + note risques")
5-15 SPIN S+P (écoute, notes 7 catégories)
15-25 SPIN I (quantifier coût: "Combien coûterait un redressement?")
25-35 SPIN N + Teach Challenger (révéler 2 risques ignorés)
35-40 Proposition 2 options + next step
```

## Verbatim ouverture

"Bonjour [Prénom], merci pour votre temps. En 40 min on va: 1) comprendre votre situation, 2) identifier les 3 risques majeurs, 3) vous proposer 2 options. Pas de pitch. À la fin vous aurez une note écrite, vous décidez tranquille. OK?"

## Questions SPIN par niche (freelance)

- S: "Facturation mensuelle? Via quoi? AE depuis quand?"
- P: "Contrat signé avec clients US?"
- I: "Si litige IP, qui possède le code? Coût 20k€?"
- N: "Si contrat FR/EN livré en 7j, quel soulagement?"

## Proposition 2 options (anchoring)

"2 options: **Essentielle 2900 DH** (contrat FR/EN + CGV) ou **Étendue 5900 DH** (Essentielle + registre 09-08 + Loom). Laquelle vous parle le plus? Pas besoin de décider maintenant, je vous envoie la convention demain."

## Silence

Après proposition → te taire 10 sec. Laisse prospect parler. Ne comble pas le vide.

## Note de risques (livrable 24h)

Template `07_Sharp_Legal_Mind/02_Cas_Grades.md` — 1 page, 3 risques H/M/B + 1 phrase client.
