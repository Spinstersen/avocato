# 01 — Pricing 3 Options : le menu qui fait choisir 5900 (pas 2900)

## Définition
Pricing 3 options = **menu 2 prix actifs + 1 leurre** : Essentiel 2900 (ancrage bas), Complet 5900 (choix cible 60%), Premium 9900 (leurre qui fait 5900 = milieu raisonnable). Sans 3 options, client compare 2900 à 0 → 2900 semble cher. Avec 3, 5900 = compromis → +22% MRR vs duo 2900/5900. Loi Doc art.264 : clause pénale 10% si impayé (pas 30%).

## Framework complet — 3 options + 7 critères

| Option | Prix HT | Inclus | Pour qui | Délai |

| **Essentiel 2900** | 2900 | Registre 5 col + déclaration assistée + modèle Word + Loom 3 min | CA 30k serré, 80 mails, budget 2900 | 7j après provision 50% |

| **Premium 9900** | 9900 | + 3 registres + convention honoraires + suivi 30j + atelier 60 min | Groupe 3 boutiques, MRE 100k dividende | 14j |

**7 critères pricing :** temps (3h30 vs 7h vs 12h), ticket évité (300k), 09-08 risque H/M/B, TVA 20%/0% art.92, provision 50% art.30, BATNA 725/h, ancre 9900→5900.

## Procédure pas-à-pas chiffrée (20 min pour pricer mission)

1. **09h00 calcule temps (5 min)** : Essentiel 2900 =3h30 (725/h BATNA 11_01), Complet 5900 =7h (842/h), Premium 9900 =12h (825/h). Temps >7h → 5900 mini.
2. **Ticket évité (5 min)** : 300k art.52 /68k AE vs 2900 =1-4% → 2900 justifié. Si 3 boutiques 300k×3=900k → 9900 =1% → premium.
3. **Ancre 9900 (2 min)** : Devis → 9900 en haut (leurre), 5900 milieu gras, 2900 bas. Client voit 9900 → 5900 = économie 4000 → choisit 5900 (60%).
4. **Devis Yousign (5 min)** : Modèle `05_Document_Bank/01_Convention_Honoraires` + 3 options tableau + TVA 20% Maroc / 0% art.92 export (SWIFT 30j glossaire §04) + provision 50% + clause pénale 10% art.264 + délai 7j + mention ICE/RC/IF art.144.
5. **Call 15 min Voss (15 min)** : Ancre 9900→5900 + perte 300k + preuve Fatima 7j (11_02) → close 5900 60%.
6. **Log MRR (3 min)** : Notion "Pricing" : option choisie / temps / MRR → 5900 = MRR cible.

## Erreurs Top 3

1. **1 prix 2900 seul → comparé à 0 → cher → négocie 1500** → corriger : 3 options 9900→5900→2900, 5900 cible.
2. **Premium 9900 sans valeur +3 livrables** → leurre détecté → corriger : 9900 = +3 registres + convention + 30j suivi (12h réelles).
3. **TVA oubliée → devis 2900 TTC vs 2900 HT → -20% marge** → corriger : devis HT + TVA 20% Maroc ou 0% art.92 export + SWIFT 30j (04).
