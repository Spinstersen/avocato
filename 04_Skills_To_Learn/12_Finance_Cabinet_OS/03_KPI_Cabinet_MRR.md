# KPI du cabinet et MRR : piloter sur 7 chiffres

> Un cabinet sans indicateurs est une salle d'audience sans dossier : tout le monde parle, personne ne sait.
> Ce fichier fixe les KPI pilotables —
> CA signé vs encaissé, transformations, panier moyen, MRR des retainers, taux de réalisation, DSO — et la discipline qui les rend utiles : 20 minutes le lundi, et ne jamais confondre un chiffre réel avec un benchmark.

## POURQUOI sept indicateurs et pas trente

- Un indicateur qui n'est pas regardé chaque semaine meurt en six semaines ; le dashboard du cabinet doit tenir dans une revue de 20 minutes le lundi matin ([[08_Metriques_Rentabilite]] pour la synthèse mensuelle).
- Les sept ci-dessous couvrent les trois maladies du cabinet jeune : vendre sans encaisser (CA signé/encaissé, DSO), travailler sans facturer (réalisation rate), et dépendre du hasard (MRR).
- La règle de vérité du vault : chaque case du dashboard est remplie avec un chiffre RÉEL relevé quelque part (banque, Notion, facture) — un benchmark n'est jamais une donnée ; les ordres de grandeur du marché sont des « hypothèses de travail à confronter à ta réalité ».

## COMMENT : les 7 KPI, définition et geste

### 1. CA signé vs CA encaissé

- **Signé** : total des conventions/propositions acceptées dans le mois, HT.
- **Encaissé** : ce qui est réellement arrivé sur le compte pro (provisions + soldes + retainers).
- L'écart des deux est le vrai tableau de bord commercial : un mois à 30 000 signés et 9 000 encaissés n'est pas un bon mois, c'est un mois de trésorerie à risque ([[02_Provision_Tresorerie]]).

### 2. Taux de transformation prospect → diagnostic

```
= diagnostics réalisés ÷ prospects entrants (atelier + SEO + referral)
Ordre de grandeur à tester, hypothèse à valider : 15-25 %
Geste si sous la cible : la promesse du diagnostic est-elle claire ?
(lien canal : 10_Public_Speaking_Ateliers/06_Suivi_Post_Atelier)
```

### 3. Taux de transformation diagnostic → mission

```
= missions signées ÷ diagnostics réalisés
Hypothèse de travail : 40-60 % — le diagnostic à 900 DH HT est conçu pour ça
(900 déduit si mission : voir 03_Sales_Without_Selling)
Geste si sous la cible : le problème n'est presque jamais le prix du pack,
c'est la remise en main propre des priorités en fin de diagnostic.
```

### 4. Panier moyen

```
= CA encaissé du mois ÷ nombre de missions signées
À suivre par gamme : combien d'Essential (2 900) vs Business (5 900)
vs Premium (12 000) — une dérive vers 100 % Essential = positionnement
qui s'effrite ou pipeline mal qualifié.
```

### 5. MRR des retainers (le chiffre qui change le sommeil)

- **MRR (Monthly Recurring Revenue)** : total HT des abonnements juridiques actifs sur le mois.
- Le catalogue : Starter 2 500 / Business 4 500 DH HT/mois ([[06_Abonnement_Retainer]]).
- Arithmétique du socle : **6 retainers Starter = 15 000 DH HT/mois garantis** avant le moindre dossier — soit ~ 2x les charges fixes du calcul-type ; c'est l'objectif structural du cabinet : transformer le one-shot en socle.
- Sous-indicateur : churn (retainers non renouvelés) — un renouvellement annuel écrit et daté (jamais de tacite reconduction silencieuse : cf. [[06_Abonnement_Retainer]]) rend le churn visible en janvier, pas en novembre.

### 6. Taux de réalisation (la santé cachée)

```
= heures facturées ÷ heures réellement travaillées
Le plancher de tout calcul de prix en dépend
(11_Negotiation_Psychology/01_BATNA_ZOPA + 01_Pricing_3_Options) ;
hypothèse de début de pratique : ~50 % ; outil : Clockify/Toggl gratuits,
5 minutes de saisie par jour.
Geste si sous la cible : le temps non facturé est commercial (ateliers,
prospection — sain) ou administratif (relances, re-saisie — à outiller).
```

### 7. DSO (Délai de paiement moyen)

```
= (créances clients ÷ CA TTC de la période) × nombre de jours
Objectif de la maison : solde payé ≤ 15 jours après livraison ;
DSO qui monte = les soldes suivent mal, ou la provision d'entrée a sauté.
Correctifs : clause de pénalités à la signature ([[04_Devis_Facture_TVA]]),
livrables finaux conditionnés au solde ([[02_Provision_Tresorerie]]).
```

## COMMENT : le dashboard Notion, 20 minutes le lundi

Une page, sept lignes, un relevé par semaine — la structure exacte :

| KPI | Cette semaine | Mois en cours | Cible | Écart → action |
|---|---|---|---|---|
| CA signé (HT) | | | | |
| CA encaissé (HT) | | | | |
| Diagnostics réalisés | | | | |
| Missions signées | | | | |
| Panier moyen | | | | |
| MRR (retainers) | | 6 × 2 500 = socle | | |
| Réalisation rate | | ≥ 50 % (à calibrer) | | |
| DSO | | ≤ 15 j | | |

- Case « Écart → action » obligatoire : un KPI sans décision attachée est un thermomètre sans traitement.
- Les totaux mois et glissants se calculent ; le passé ne se réécrit jamais (une erreur relevée est corrigée par la ligne du dessous, pas par retouche).

## La ligne rouge : réel vs benchmark

| Ce que vous mesurez | Ce que le marché dit | Comment le vault note l'un et l'autre |
|---|---|---|
| « Mon panier moyen = 3 400 » | « Les cabinets de la place afficheraient 4 000 » | Le premier est une donnée, le second une hypothèse de travail à vérifier chez soi, jamais à publier comme un fait |
Tous les « 15-25 % » et « 40-60 % » de ce fichier sont des cibles initiales de paramétrage, pas des normes : au troisième trimestre, ils seront remplacés par vos propres médianes — et c'est là, pas avant, qu'ils deviendront pilotables.

## EXEMPLE : [cas illustratif] le trimestre qui mentait

Un trimestre à 62 000 DH signés, MRR de 5 000, et trésorerie à 11 000.
Le dashboard du lundi fait apparaître l'écart : CA encaissé 23 000, DSO à 70 jours.
Diagnostic des lignes : les deux Premium du trimestre ont été signés sans solde conditionné (provision encaissée, livrables livrés, soldes « attendus »), et l'un des 6 retainers n'a jamais été re-signé pour l'année (tacite reconduction héritée — proscrite depuis [[06_Abonnement_Retainer]]).
Trois lignes d'action : solde avant dernier livrable, renouvellement écrit chaque janvier, relance à J+20 automatique.
Le trimestre suivant : CA signé 55 000, encaissé 48 000.
Moins de chiffres « de croissance », plus de réalité.

> **Lecture pro :** Les quatre premières semaines, le dashboard ment un peu — pas parce que les chiffres sont faux, mais parce que vous n'avez pas encore d'historique pour les interpréter.
> La règle pendant ce mois-là : noter sans décider.
> Décider avec un écart de KPI qu'on ne comprend pas, c'est confondre un thermomètre capricieux et une fièvre.
