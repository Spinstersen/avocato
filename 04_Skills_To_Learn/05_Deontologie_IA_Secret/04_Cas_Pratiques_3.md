# 04 — 3 cas pratiques

> Trois scénarios du cabinet, traités sans jamais exposer les clients.

## Cas 1 — Rédiger un contrat freelance offshore (niche 01)
- **Danger** : coller le contrat EN signé du client pour « l'améliorer ».
- **Bonne pratique** : extraire la structure (objet, paiement, IP, résiliation) en clauses types anonymisées ; demander à l'IA 3 variantes de formulation ; choisir, adapter, compléter par la Clause Library (`13/02-06`).
- **Vérification** : IP = loi 2-00 (cession écrite, droit par droit) ; TVA art. 92 si export ; signature 53-05.

## Cas 2 — Synthèse d'une liasse comptable (niche 06/08)
- **Danger** : coller le bilan avec dénomination et ICE pour « résumer ».
- **Bonne pratique** : ne transmettre que les postes en % (compte courant anormal, charges perso, stock) ; l'IA aide à formuler les questions au comptable, pas à qualifier le dossier.
- **Vérification** : chaque question renvoie au CGI/à la liasse ouverte ; le cabinet qualifie, le comptable chiffre.

## Cas 3 — Réponse à un client paniqué (toutes niches)
- **Danger** : faire rédiger par l'IA une réponse contenant les faits réels et les pièces.
- **Bonne pratique** : IA = structure du message (fait / conséquence / action) ; les faits sont ajoutés par l'avocat après relecture ; jamais de WhatsApp pour une mauvaise nouvelle.
- **Vérification** : aucune promesse de résultat (loi 66-23) ; délais et articles vérifiés avant envoi.
