# 05 — Déontologie IA et secret (ce qu'on ne prompt jamais)

> Dossier de garde-fous : ce qui reste hors du LLM, comment anonymiser, comment valider avant de signer. Vérifié 10/09/2026 — secret (loi 66-23, ex art. 36/59), données (loi 09-08), LAB-FT.

## TL;DR
- L'IA brouillonne ; l'avocat ouvre le texte et signe.
- Jamais de donnée identifiante en clair dans un outil public.
- Toute sortie IA est validée 3V (version, vérification, visa) avant livraison.
