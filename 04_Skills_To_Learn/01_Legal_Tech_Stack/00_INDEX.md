# 01 — Legal Tech Stack : la stack technique de l'avocat

> **Dossier maître — Skills n°1.** La stack technique complète pour un avocat d'affaires trilingue tech-savvy.

## TL;DR

Stack minimal : Notion + Google Workspace + Calendly + Yousign + Loom + Canva + Stripe + Plausible. Coût ~100 USD/mois. Délégation possible après 12 mois.

## Total : ~100-150 USD/mois (1 000-1 500 DH)

## Délégation progressive (après 12-18 mois)

- Production visuelle : freelance graphiste.
- Montage vidéo : freelance monteur.
- Animation réseaux sociaux : community manager.
- Suivi administratif : assistant virtuel.

## Principe

> Commencer petit, ajouter les outils qui manquent au fur et à mesure. La stack évolue avec le cabinet.
