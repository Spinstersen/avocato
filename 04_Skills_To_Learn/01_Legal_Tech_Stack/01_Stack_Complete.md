# 01 — Stack complète : configuration et workflow

## 1. La configuration Notion

### Dashboard

- 3 MITs du jour.
- Calendrier de la semaine.
- Liens rapides.
- Dopamine Board.

### Bases de données

- CLIENTS (1 page par client).
- MISSIONS (1 page par mission).
- CONTENT (idées, brouillons, publiés).
- PROSPECTS (1 page par prospect).
- PARTENAIRES (1 page par partenaire).
- TEMPLATES (modèles-type).
- VEILLE (articles lus).
- KPI (board hebdo).

## 2. La configuration Google Workspace

- Email professionnel : `nom@cabinet.ma`.
- Drive partagé avec un associé (si applicable).
- Calendar synchronisé avec Calendly.
- Meet pour visios.

## 3. La configuration Calendly / Cal.com

- Types d'événements : diagnostic 45 min, visio mission 30 min, atelier 60 min.
- Créneaux : 9h-12h, 14h-17h (sauf jours off).
- Buffer : 15 min avant/après.
- Confirmation par email automatique.
- Annulation 24h avant.

## 4. La configuration Yousign

- Templates de convention-type.
- Workflow : envoi → signature → retour → archivage Notion.
- Notifications par email.

## 5. La configuration Loom

- Templates de vidéos : introduction mission 3 min, clôture 10-15 min, explication de clause 5 min.
- Dossier de stockage partagé avec le client.

## 6. La configuration Stripe (si toléré RIO)

- Produits : Diagnostic 600 DH HT, Pack Freelance 2 900 DH HT, etc.
- Page de paiement sobre.
- Pas de logos de cartes criards.
- Politique de remboursement claire.

## 7. Le workflow type d'une mission

```
Intake Tally
  ↓
Diagnostic Calendly + Visio Meet
  ↓
Convention Yousign + Provision Stripe
  ↓
Notion de mission créé
  ↓
Production + Looms ponctuels
  ↓
Livraison Notion + PDF + Loom
  ↓
Facture solde Yousign + Stripe
  ↓
Suivi email + abonnement
```
