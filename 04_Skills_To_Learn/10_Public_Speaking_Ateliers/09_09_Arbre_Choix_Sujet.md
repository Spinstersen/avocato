# 09 — Arbre de Choix Sujet : quel atelier faire mardi prochain ?

## Définition
Arbre sujet = **decision tree 4 questions binaires** qui élimine 9/10 sujets en 5 min pour choisir l'atelier qui maximise présents + conversion 2900/5900. Sans arbre, on choisit sujet qui nous plaît ("Loi 2-00 IP") → 9 présents NPS 7. Avec arbre, sujet = top KW GSC pos 11 (09_06) → 20 présents NPS 9 + 8 audits. 4 questions = 5 min.

## Framework complet — Arbre 4 niveaux

```
Q1 SEO top 10 ? (GSC pos <20 J30) ──NON→ file P3 (pas d'audience)
  └─OUI (ex: "registre CNDP" pos 11)
Q2 Ticket ≥2900 ? (CGV 4900 / registre 2900 / AE 12k) ──NON→ P3
  └─OUI
Q3 Peur chiffrée 300k/68k/45j ? (sanction CNDP/DGI) ──NON→ P2 (info)
  └─OUI (art.52 300k)
Q4 Tu as cas live 5 min ? (Excel 5 col / CGV / IS 15%) ──NON→ prépare live sinon P2
  └─OUI → SUJET MARDI (01_Anatomie + 02_SCQA)
```

## Procédure pas-à-pas chiffrée (5 min / choix, 20 min pour 5 sujets)

1. **Liste 5 sujets (2 min)** : Depuis 09_05 calendrier (12 KW) + 09_06 pos J30. Prends 5 KW pos <20. Ex: registre 11, CGV 9, AE 14, TVA 92 pos 18, OMPIC 1200 DH pos 22.
2. **Q1 SEO pos (1 min)** : GSC 09_06 → OMPIC pos22 → Q1 NON → écarte (pas d'audience). Restent 4.
3. **Q2 Ticket (1 min)** : Tous ticket ≥2900 → passent (registre 2900, CGV 4900, AE 12k, TVA 4900).
4. **Q3 Peur chiffrée (1 min)** : Tous peur 300k/68k → passent.
5. **Q4 Live 5 min (1 min)** : TVA art.92 live = facture + SWIFT 30j → oui. Tous passent → départage = **pos la plus basse (meilleure)** → CGV pos9 gagne → mais registre pos11 + live Excel plus visuel → registre #1 (live 5 min > tableau TVA).
6. **Décision + brief (14 min)** : Choisis registre → script SCQA Fatima 90s (02) + 10 slides (03) + live Excel (04) → atelier mardi.
