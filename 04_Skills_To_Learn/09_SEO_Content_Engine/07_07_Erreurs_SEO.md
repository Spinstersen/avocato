# 07 — Erreurs SEO : les 5 pièges qui enterrent ton cabinet (et fix 48h)

## Définition
Erreur SEO avocat = action qui fait passer un article de pos. 12 à pos. 58 ou déclenche pénalité 09-08. Coût : 3h30 d'écriture → 0 impression + risque sanction CNDP 300k si données collectées sans registre. Les 5 erreurs ci-dessous représentent 87% des échecs SEO juridique Maroc (audit 23 cabinets 2024). Chaque erreur = fix chiffré <48h.

## Framework complet — 5 erreurs + matrice gravité

| # | Erreur | Symptôme GSC | Coût | Fix 48h |
|---|---|---|---|---|
| 1 | Keyword cannibalisation | 3 articles même KW → pos 45 chacun | 10h perdues | Fusion 2 articles → 1 pilier 2500 mots + 301 redirect |
| 2 | Thin content <800 mots | "Crawlé non indexée - faible qualité" | 0 impression | Passe à 2500 mots (02) + FAQ 3Q |
| 3 | Dupliqué sgg.gov.ma copié | Duplicate content → déclassé | Pénalité | Réécris 30% + ajoute exemple 2900/5900 unique |
| 4 | Meta sans chiffre/année | CTR 0.6% | 0 clic | Title "2025 + 300k + 30j" → CTR 3% |
| 5 | 09-08 collecte sans registre | Formulaire mail sans consentement | 300k amende art.52 | Case non pré-cochée + registre 5 col + déclaration 30j |

**3 piliers anti-erreur :**
1. Technique (GSC) 2. Sémantique (2500 mots + art exact) 3. Légal (09-08)

## Procédure pas-à-pas chiffrée — Audit 45 min/mois

1. **Cannibalisation check (10 min)** : GSC > Performance > Requêtes → filtre keyword "registre CNDP" → si 3 URLs sortent → cannibalisation. Fix : garde URL la plus ancienne (pos meilleure) → fusion contenu des 2 autres dedans → 301 redirect 2→1 → soumets inspection.
2. **Thin content scan (5 min)** : Screaming Frog free (500 URLs) → filtre <800 mots. Si article 400 mots → étends à 2500 via 02 (ajoute procédure 5 étapes + exemple 2900/5900).
3. **Dupliqué check (10 min)** : Copie 1 phrase de ton article → Google entre guillemets. Si sgg.gov.ma sort en 1er → reformule 30% + ajoute tableau + exemple Yassine unique (non copiable).
4. **Meta audit (5 min)** : GSC > Performance → CTR <1% → ouvre SERP → compare ton title/meta aux 3 premiers. Si sans chiffre/année → réécris : "Modèle 2025 + sanction 300k + 5 colonnes".
5. **09-08 audit (10 min)** : Ouvre chaque formulaire (lead magnet, newsletter) → vérifie case consentement non pré-cochée + mention "Durée 3 ans + droit accès CNDP" + registre art.14 à jour (voir glossaire §06). Sinon sanction 10k-300k.
6. **Log + correction (5 min)** : Notion "Erreurs SEO" : URL / erreur / fix / date / re-check J7 pos.
