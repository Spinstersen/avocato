# 01 — SEO Long-Tail Keywords Avocat : 0 concurrence → Intent achat 10/10

## Définition
Long-tail = requête ≥4 mots, volume 10-150/mois, difficulté KD <15, intent transactionnel clair. À l'inverse du short-tail ("avocat Maroc" KD 89, intent flou), la long-tail capte quelqu'un qui cherche une solution payante immédiate. Ex: "modèle contrat prestation freelance Maroc Word" = 38 recherches/mois, KD 6, intent 10/10 → 1 article = 1 lead qualifié à 2900 DH.

## Framework complet — 3 piliers Long-Tail Avocat

| Pilier | Critère | Outil | Seuil avocat 2025 |
|---|---|---|---|
| **Intent** | Achat > Info | SERP check | "modèle", "prix", "sanction", "obligatoire" = achat |
| **Difficulté** | KD <15 | Ubersuggest / Ahrefs free | KD 5-10 = publiable J+7 |
| **Volume** | 20-150 | Google Suggest + GSC | <20 = trop niche, >150 = trop concurrentiel |

**7 catégories long-tail avocat Maroc 2025 :**
1. Contrats freelance (ex: "contrat prestation freelance Maroc 2025")
2. E-commerce CGV (ex: "CGV YouCan Maroc modèle")
3. Données 09-08 (ex: "registre traitement CNDP modèle Excel")
4. Statut juridique (ex: "AE vs SARL plafond 500k 2025")
5. Propriété intellectuelle (ex: "clause cession IP freelance Loi 2-00")
6. Honoraires / provision (ex: "convention honoraires avocat Maroc art 30")
7. MRE / offshore (ex: "créer SARL MRE distance OMPIC")

## Procédure pas-à-pas chiffrée (90 min)

1. **Brainstorm 30 keywords (20 min)** : Google Suggest tape "contrat freelance M" → note autocomplétions. Répète pour CGV, 09-08, SARL.
2. **Filtre KD/Volume (20 min)** : Colle liste dans Ubersuggest gratuit (3 recherches/jour → étale sur 10j ou Ahrefs Keyword Generator). Garde KD ≤15, Vol ≥20.
3. **SERP intent check (15 min)** : Google chaque keyword. Si top 5 = PDF sgg.gov.ma + forums = intent info faible → écarte. Si top 5 = modèles payants / avocats = intent achat → garde.
4. **Score Ticket (10 min)** : Associe ticket moyen : "CGV" = 4900 DH, "contrat freelance" = 2900 DH, "09-08 sanction" = 12k. Priorise Ticket × Volume / KD.
5. **Tableau final (15 min)** : 20 keywords triés par score. Choisis 1 keyword = 1 article (voir 10_Arbre_Choix_MotCle).
6. **Validation GSC (10 min)** : Après publication, vérifie impressions J+7 dans GSC → si <5 impressions ajuste title H1.

## Erreurs Top 3

1. **Viser "avocat Maroc" (KD 78)** → 0 trafic 6 mois → corriger : long-tail KD <15, publie 1/semaine, accumule 12 articles = 400 impressions/mois en 90j.
2. **Keyword info sans ticket ("qu'est-ce que la loi 09-08")** → trafic mais 0 conversion → corriger : ajouter "modèle / prix / sanction" au keyword.
3. **20 keywords / 1 article** → cannibalisation → corriger : 1 keyword principal + 2 secondaires max, voir 02_Structure_Article_2500.
