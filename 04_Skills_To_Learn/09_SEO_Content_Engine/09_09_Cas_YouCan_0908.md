# 09 — Cas YouCan 09-08 : boutique 30k/mois mise en demeure 45j → conforme en 7j

## Définition
Cas YouCan_0908 = boutique YouCan/Shopify marocaine typique (30k CA/mois, 50 commandes/j, 2000 mails collectés) qui reçoit **mise en demeure CNDP 45 jours** pour absence registre art.14 + transfert Shopify US sans clauses art.43. Sanction encourue : 10k-300k DH art.52 + blocage. Objectif : passer de "0 registre" à "conforme + 4 articles SEO 09-08 qui rankent" en 7 jours. Tiré de jurisprudence CNDP 2023-045.

## Framework complet — 3 piliers conformité YouCan

| Pilier | Obligation Loi 09-08 | Preuve | Délai |
|---|---|---|---|
| **Registre 5 colonnes art.14** | Traitement prospection + commandes | Excel 5 col (finalité/base/durée/destinataires) | J1 |
| **Déclaration CNDP art.12** | Déclaration en ligne cndp.ma | Récépissé 30j | J1 dépôt, J30 récépissé |
| **Transfert art.43-44** | Shopify/AWS US = transfert → clauses types CNDP | Politique confidentialité + contrat sous-traitant art.24 | J3 |

**7 étapes boutique YouCan 30k :**
1. Collecte : 2000 mails + téléphones + adresses (donnée personnelle dès 1 mail)
2. Base légale : consentement (case non pré-cochée) + contrat (commande)
3. Durée : 3 ans après dernier contact (prospection) + 10 ans factures (CGI)
4. Destinataires : YouCan (sous-traitant art.24) + Mailchimp si newsletter
5. Politique confidentialité : mention transfert US + droits CNDP
6. Articles SEO : 4 long-tail 09-08 (registre, transfert, sanction 300k, modèle)
7. GSC indexation 03 : 4 articles indexés <48h → trafic "09-08" → leads 2900

## Procédure pas-à-pas chiffrée (7 jours)

1. **J1 Audit 45 min** : Liste traitements : newsletter (2000 mails), commandes (50/j), SAV WhatsApp. Pour chaque : finalité/base/durée/destinataire. Ouvre cndp.ma → Déclaration → formulaire traitement "prospection" → dépose J1 (récépissé 30j).
2. **J1 Excel 5 colonnes (30 min)** : Template : | Traitement | Finalité | Base légale | Durée | Destinataires | → rempli pour 3 traitements. Sauvegarde Notion + imprime.
3. **J2 Politique confidentialité (60 min)** : Page /confidentialite : mention art.14 registre + art.43 transfert Shopify US + droits (accès/rectif CNDP) + durée 3 ans + contact DPO. Inspire cndp.ma modèle.
4. **J3 Clauses sous-traitant (30 min)** : YouCan = sous-traitant art.24 → ajoute annexe contrat YouCan + Mailchimp clauses types CNDP (cndp.ma). Mention dans registre.
5. **J4-6 Articles SEO (3×3h30)** : 02_Structure 2500 mots : #1 "Registre CNDP 5 colonnes modèle Excel", #2 "Shopify transfert 09-08 art.43", #3 "Sanction CNDP 300k mise en demeure 45j". Chaque article + 2 options 2900/5900.
6. **J7 GSC + preuve (30 min)** : Soumets 3 articles GSC 03 → index 48h. Archive dossier : registre + récépissé CNDP + politique + clauses → envoie CNDP réponse mise en demeure 45j.
7. **J30 suivi** : Récépissé CNDP reçu → classe. GSC pos J30 : "registre CNDP" pos 11 (110 imp), 2 leads 2900.

## Erreurs Top 3

1. **"Je suis petite boutique 30k, pas concernée"** → dès 1 mail = 09-08 → corriger : registre obligatoire dès 5 contacts (CNDP 2023-045 sanction 30k pour 80 mails).
2. **Case pré-cochée "j'accepte newsletter"** → consentement invalide art.12 → corriger : case vide non pré-cochée + preuve horodatée.
3. **Shopify US sans mention transfert** → art.43 violation → corriger : politique mention "transfert US + clauses types CNDP" + registre colonne destinataires.
