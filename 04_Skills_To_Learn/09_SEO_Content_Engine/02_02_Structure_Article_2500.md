# 02 — Structure Article 2500 mots : le squelette qui ranke en 7 jours

## Définition
Un article SEO avocat qui ranke = **2500 mots (±10%)**, **H1 unique + 5-7 H2**, **meta title 58c + description 155c**, **3 internal links**, **1 lead magnet**. En-dessous de 1800 mots Google le classe "thin content" ; au-delà de 3200 mots le taux de lecture chute à 22% (Search Engine Journal 2024). 2500 = sweet spot juridique Maroc.

## Framework complet — 3 piliers + 7 blocs

**Pilier 1 — Technique (pour Google) :** H1 = keyword exact, URL courte /mot-cle, 1 image alt keyword, temps chargement <2s.
**Pilier 2 — Sémantique (pour ranker) :** keyword principal 8-12×, 2 secondaires, champ lexical (CNDP, art.14, sanction 300k), FAQ schema.
**Pilier 3 — Conversion (pour vendre) :** CTA 2900/5900 en 3 endroits, preuve sociale (cas Yassine), lead magnet modèle Word.

**7 blocs obligatoires (2500 mots répartis) :**
| Bloc | Mots | Rôle |
|---|---|---|
| 1. Hook + définition (H1) | 200 | Définit concept en 2 phrases + sanction chiffrée |
| 2. Base légale tableau | 350 | Art exact sgg.gov.ma + 3 conditions |
| 3. Procédure pas-à-pas | 600 | 5 étapes numérotées, délais 30j/7j, coûts 1200 DH |
| 5. Erreurs Top 3 | 300 | Erreur → coût → correction |
| 6. Checklist 12 points | 250 | Cases à cocher contextuelles |
| 7. FAQ 3 Q + CTA | 400 | Schema FAQ + renvoi glossaire |

## Procédure pas-à-pas chiffrée (3h30 par article)

1. **Brief KW (20 min)** : Prends 1 keyword de 01_SEO_LongTail. Ex: "registre traitement CNDP modèle". Vérifie KD <15.
2. **SERP scan (20 min)** : Ouvre top 5. Note H2 manquants. Ton article couvrira ce qu'ils oublient (ex: délai 30j CNDP, art.14 5 colonnes).
3. **Plan H2 (20 min)** : 6 H2 = Définition / Base légale art.14 / Procédure 5 étapes / Exemple 2900-5900 / Erreurs / Checklist. Chaque H2 = 350-600 mots.
4. **Rédaction (90 min)** : 2500 mots, LanguageTool 0 faute, 1 phrase = 18 mots max. Cite art exact : "Loi 09-08 art.14 registre".
5. **SEO on-page (20 min)** : Title 58c "Registre CNDP 09-08 : modèle 5 colonnes + sanction 300k [2025]", meta 155c, URL /registre-cndp-modele, 3 internal links (vers 01, 03, 06).
6. **Lead magnet (20 min)** : Encadré "Télécharge modèle Excel 5 colonnes → mail" (09-08 consentement case non pré-cochée).
7. **Publish + GSC (20 min)** : Publie, soumets URL dans GSC inspection → demande indexation (voir 03_GSC).

## Erreurs Top 3

1. **Mur de texte 2500 mots sans H2/tableau** → bounce 82% → corriger : 1 tableau/500 mots + checklist + encadré prix.
2. **Citer "selon la loi" sans art** → 0 crédibilité + hallucination IA → corriger : cite "Loi 09-08 art.14, sgg.gov.ma, vérif 20/08/2026".
3. **CTA unique en fin** → 1.1% conversion → corriger : CTA après bloc 1, 4 et 7 (3×) avec 2 prix 2900/5900 (effet ancrage).
