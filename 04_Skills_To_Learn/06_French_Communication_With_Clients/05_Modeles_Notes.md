# 04 — Modèles Notes Juridiques

## Template note 1 page

```
# Note — [Sujet] — [Client anonymisé] — [Date]
## 1 Question
## 2 Cadre légal (art)
## 3 Analyse SCQA
## 4 Conclusion (1 phrase)
## 5 Recommandations (3 bullets + devis)
Signature sobre.
```

## 3 exemples

- Note AE plafond 400k → reco SARL
- Note 09-08 ecom → reco registre
- Note IP freelance → reco clause cession

Chaque note: 1 chiffre risque (ex: amende 300k) + 1 phrase client.
