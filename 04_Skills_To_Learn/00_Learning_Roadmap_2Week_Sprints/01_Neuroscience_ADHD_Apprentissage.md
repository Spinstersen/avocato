# 01 — Neuroscience de l'Apprentissage ADHD-Avocat

> 30 min/jour bat 3h le dimanche. Ce n'est pas de la motivation, c'est de la neurochimie.

## 1. Pourquoi le cerveau ADHD oublie

- **Mémoire de travail faible (7±2 → 3±1 chez ADHD):** ce qui n'est pas externalisé est perdu. → Solution: Notion Learning page `03_Systeme_Suivi_Notion_Learning.md`.
- **Déficit dopamine tonique:** besoin de récompense immédiate. Lecture passive = 0 dopamine → abandon J3. Production visible (case cochée, article publié) = dopamine → continuation.
- **Hyperfocus vs initiation:** démarrer est dur (friction), continuer est facile. → Règle des 5 minutes + templates.

## 2. Les 3 piliers validés

### A. Spaced Repetition (Anki-like sans Anki)
Revoir à J1, J3, J7, J30. Pour un avocat: relire la note de risques J3, réexpliquer à un ami J7. Pas d'outil complexe — Notion rappel suffit.

### B. Active Recall > Relecture
Fermer le livre, écrire 3 bullets de mémoire. Si tu ne peux pas, tu n'as pas appris. Test client-facing: "Explique la clause pénale DOC en 1 phrase client + 1 chiffre risque."

### C. Interleaving (mélanger)
Mardi droit 09-08, mercredi IA, vendredi business. Le mélange force le cerveau à discriminer, donc à retenir mieux que le bachotage d'un seul sujet.

## 4. Protocole 30 min ADHD-proof

```
Min 0-2 : ouvrir template sprint (friction 0)
Min 2-12 : input actif (vidéo 10 min + notes manuscrites 3 bullets)
Min 12-22 : output (réécrire en tes mots + 1 phrase client)
Min 22-27 : spaced check (relire note J-3)
Min 27-30 : cocher habit tracker + planifier demain
```

## 5. Erreurs fatales

1. Apprendre le matin avant Deep Work → tu procrastines la mission payante.
2. Prendre des notes verbatim → 0 traitement. Reformule.
3. Lire sans deadline sociale → "vendredi j'explique à [comptable] en 5 min" = deadline.
