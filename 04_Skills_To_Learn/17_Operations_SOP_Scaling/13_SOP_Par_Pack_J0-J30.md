# SOP par pack (1 page par mission — J0-J30, pièces, done)

> 1 SOP = 1 pack vendu. J0 provision → J30 clôture + abonnement. Vérifié 07/09/2026.

## SOP type (copier par pack)

**J0 kickoff.** Convention 66-23 + provision 50% + lettre mission (jalons J0/J2/J5/J7) + collecte pièces (KYC, contrats, relevés). Done = provision encaissée + rythme créé (webapp).
**J2 checkpoint.** 1 brique faite + 1 manquante datée. Done = e-mail court envoyé.
**J5 presque fini.** Question ouverte unique + date livraison. Done = réponse ou relance datée.
**J7 paquet de quatre.** Livrables (`05/09-16`) + note risques + restitution Loom/visio + mode d'emploi. Done = PV remise signé → facture solde.
**J30 clôture.** Archivage + referral + fenêtre retainer (veille 4 500, revue annuelle, registre tenu). Done = abonnement proposé.

## SOP par pack (pièces spécifiques)

* Freelance offshore : contrat `05/03` + registre `05/09` + note statut.
* E-commerce : CGV `05/04` + confirmation écrite + registre retours + dotation `02/15`.
* 09-08 : registre `05/05` + DPA `05/13` + récépissé CNDP.
* MRE : pacte/procuration `05/14` + généalogie `10/15` + PV dividende `05/10`.
* Change : registre + dossier banque `09/15` + transaction `09/14`.
* IP : recherche + dépôt + cession `05/16`.
* Nomade : titre `11/14` + résidence + banque `11/16`.
