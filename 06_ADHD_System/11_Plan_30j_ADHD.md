# 11 — 30-Day ADHD Launch Plan (EN)

> One month to install the system, not to change your life. Actions only, 45–90 min/day.

## TL;DR
- Week 1: setup (calendar, Notion, focus tools, daily MITs).
- Week 2: momentum (5 outreach/day, first diagnostics, posting).
- Week 3: compounding (deliver, ask referrals, batch content).
- Week 4: review and lock the system for month 2.

## Week 1 — Setup (no client work required)
| Day | Action (45 min) |
|---|---|
| 1 | Brain-dump everything, pick ONE niche (`02_Niches_Deep_Dive/`) |
| 2 | Create the calendar blocks (deep/shallow/outreach/review) |
| 3 | Build the 4 Notion databases (Clients, Missions, Content, Learning) |
| 4 | Install Forest/Freedom, test one 25-min cycle |
| 5 | Write the Daily 3 MITs template + habit tracker on paper |
| 6 | Choose ONE acquisition channel (`03_Acquisition_Without_Ads/`) |
| 7 | Sunday review + one small reward |

## Week 2 — Momentum
- Every day: 3 MITs + 5 outreach messages (script from the chosen channel).
- Tuesday: first diagnostic booked (even free/20 min to practise).
- Thursday: publish post #1 (educational, no promise of result).
- Sunday: review, batch 3 content titles, reward.

## Week 3 — Compounding
- Deliver the first paid mission end-to-end (SOP in `04_Skills_To_Learn/17_Operations_SOP_Scaling/02_Bibliotheque_SOP_Pack_Freelance.md`).
- Ask for one referral at closing + 48h (`04_Skills_To_Learn/16_Client_Ops_Experience/07_Demander_le_Referral.md`).
- Publish 2 posts, contact 3 partners (comptables/fiduciaires).
- Sunday: review + prune what drained you.

## Week 4 — Lock it
- Second pack or first retainer proposal.
- Update the KPI tracker and dopamine board.
- One improvement only: the highest-friction step gets a template or a script.
- Decide: same niche and channel for the next 60 days (90-day rule).

## Success metrics at D30 (actions, not luck)
- [ ] Calendar blocks held 20/30 days
- [ ] 100+ outreach messages sent
- [ ] 5+ diagnostics delivered
- [ ] 2+ packs signed
- [ ] 1 referral requested
- [ ] System still alive after a bad day (MVD used at least once)
