# 09 — Fiches & Templates ADHD (EN)

> If it isn't written, it doesn't exist. Every template below is copy-paste, not inspiration.

## TL;DR
- Five templates run the whole system: Daily MITs, Habit tracker, Dopamine board, Weekly sprint, Bad-day MVD.
- Keep them on ONE page (paper or Notion), visible.
- Print beats digital for the daily ones.

## Template 1 — Daily 3 MITs
```
Date: ____
MIT 1 (Revenue):    _______________________  [ ]
MIT 2 (Visibility): _______________________  [ ]
MIT 3 (Delivery):   _______________________  [ ]

Later (not today):  _______________________
Tomorrow's first action: _________________
```
Rule: cross off or move — no half-done third task.

## Template 2 — Habit tracker (7 days)
| Habit | L | M | M | J | V | S | D |
|---|---|---|---|---|---|---|---|
| 3 MITs chosen | | | | | | | |
| 1 post or 5 comments | | | | | | | |
| 5 outreach messages | | | | | | | |
| 90-min deep work | | | | | | | |
| Inbox 2× only | | | | | | | |

Goal: never break the chain 5 days in a row.

## Template 3 — Dopamine board (visible wins)
- Diagnostics booked: __ (target 5/month)
- Packs signed: __ (target 2/month)
- Posts published: __
- Partners contacted: __ (target 3)
- CA encaissé: __ DH

Visible client count beats "brand awareness". Update every Friday.

## Template 4 — Weekly sprint page (Notion)
```
Week #__  (Mon __/__ -> Sun __/__)
Theme: ______________________
3 MITs:  1) ______  2) ______  3) ______
Content titles: 1) ______ 2) ______ 3) ______
Review: wins / misses / one improvement
```

## Template 5 — Bad-day MVD (45 min)
```
[ ] 15 min revenue action: ____________
[ ] 15 min delivery: __________________
[ ] 15 min shutdown + tomorrow's 3 MITs
Done = a complete day. Full stop.
```
