# 08 — Tech Stack ADHD (EN)

> One tool per job, setup once, then no more tool-shopping. Tool-hopping is procrastination in disguise.

## TL;DR
- Core stack: Notion (brain) + Google Calendar (time) + Forest/Freedom (focus) + WhatsApp Business (CRM).
- Budget: about $25–30/month. Cheaper than one lost client.
- Rule: no new tool for 90 days. If something does not work in 2 weeks, delete it.

## The stack by job
| Job | Tool | Setup |
|---|---|---|
| Second brain / CRM | Notion | Cabinet OS template (`04_Skills_To_Learn/01_Legal_Tech_Stack/02_Notion_Cabinet_OS_Detaille.md`) |
| Time | Google Calendar | Color-coded blocks (red deep, blue calls, grey admin) |
| Focus | Forest app + Freedom | Block social/news during the 10:00 block |
| Sound | Brain.fm / brown noise | No lyrics, same playlist daily |
| Dictation | Whisper / phone dictation | Draft emails and notes by voice |
| Meetings | Calendly | 20/45 min slots, buffer between calls |
| Client chat | WhatsApp Business | Labels: New / Diagnostic / Devis / Client / Partenaire |
| Notes/scan | Phone + Drive | One folder per client, named `NOM_ICE_date` |
| Admin automation | Zapier / Make (free tier) | Diagnostic form → Notion row → email |

## Setup order (one 45-min block each)
1. Calendar: the daily blocks (deep, shallow, outreach, review).
2. Notion: Clients, Missions, Content, Learning. No more than 4 databases.
3. WhatsApp Business: labels + welcome/absence messages.
4. Focus: Forest + Freedom installed and tested on one block.
5. Calendly + Tally form linked to Notion (later, when the first lead arrives).

## Anti-tool-hoarding rules
- One tool per job. Two tools = zero system.
- No purchase without a 7-day need (write the need down; if it repeats, decide).
- Every quarter, delete one unused subscription.
- Automation only after the manual SOP exists (`04_Skills_To_Learn/17_Operations_SOP_Scaling/01_Theorie_SOP_Pour_Avocat.md`).
