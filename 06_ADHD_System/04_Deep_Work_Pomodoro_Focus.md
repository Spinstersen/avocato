# 04 — Deep Work & Pomodoro (EN — ADHD)

> The money is made in the 90-minute block, not in the 10-hour day. Protect ONE block; the rest is bonus.

EN ADHD — 90m blocks, Pomodoro 25+5, Freedom/Cold Turkey, Brain.fm. 3 MITs. Timebox calendar. FR rules live in `01_Strategy/05_ADHD_Operating_System_Overview/03_Regles_Fondamentales.md`; this file is the EN execution layer.

## TL;DR
- Deep work = 1 block/day, 90 min, same time, phone in another room.
- Pomodoro 25+5 ×3, then a 15-min reward. Stop at the timer, not at "done".
- If the day collapses: do 25 min only. A 25-min block is a win; zero is not allowed.

## The 3 MITs (10 min, with coffee)
1. **Revenue MIT** — outreach, devis, diagnostic call.
2. **Visibility MIT** — 1 post or 5 comments.
3. **Delivery MIT** — the client work that must move.

Only 3. Everything else goes to "Later" (a real list, not your head).

## Daily block (timeboxed)
| Time | Block | Rule |
|---|---|---|
| 10:00–11:30 | Deep Work (MIT 3) | Phone in another room, tabs closed, timer on |
| 11:30–12:00 | Shallow | WhatsApp/email replies only |
| 15:00–16:00 | Outreach / content | MIT 1 + MIT 2 |
| 18:00–18:30 | Review | 3 MITs for tomorrow + shutdown |

## Pomodoro protocol (25+5 ×3)
- 25 min: one task only — no "quick check" of anything.
- 5 min: stand, walk, water. NOT phone.
- After 3 cycles: 15 min real reward (coffee outside, episode, walk).
- Write the next action on paper before the break ends — re-entry is the hard part, not the work.

## Friction killers (do BEFORE 10:00)
- [ ] Template/file for the task already open.
- [ ] Notifications off (phone other room, desktop DND).
- [ ] One tab rule: the doc you work on + the source you cite.
- [ ] Water + coffee on the desk (no "I'll get up in a minute").

## Focus stack
- **Freedom / Cold Turkey**: block LinkedIn, YouTube, news during the block.
- **Brain.fm / brown noise**: no lyrics. Same playlist = same trigger.
- **Forest app**: phone face down, tree growing = visual stake.
- **Calendar block**: red = deep, blue = calls, grey = admin. Defend red like a hearing.

## When you can't start (ADHD wall)
1. Shrink: do the first 2 minutes only (open the doc, write the title).
2. Body double: Focusmate/Flown or café — presence does the work (`05_Dopamine_Menu_Body_Double.md`).
3. Swap MIT: revenue → visibility if the resistance is administrative.
4. Still stuck after 3 attempts: log it, stop, go outside. Tomorrow's block starts at 10:00 anyway (`07_Recovery_Protocols.md`).
