# 08 — Arbre de Décision 90-Day : quelle niche, quel canal, quel rythme ?

> **À utiliser :** avant de démarrer le plan 90 jours (S1) et à chaque pivot (S6, S13). 5 min, 6 questions.

---

## Question 1 — Quelle niche pour les 90 prochains jours ? (choisir 1 seule)

```
Parlez-vous anglais couramment (call 30 min sans préparation) ?
├─ OUI → Freelancers & agences offshore (#1) — le plus rapide pour vous
│         Pourquoi : anglophone, sur LinkedIn/FB, besoin contrat FR/EN + TVA art.92 + rapatriement 30j
│         Premier client : 2–3 semaines | Ticket : 900 diag + 3 500–5 500 pack | Dossier : `02_Niches_Deep_Dive/01_Freelancers_Agencies_Offshore/00_INDEX.md`
└─ NON → E-commerce YouCan (#2) — volume + FB groups
          Pourquoi : francophone, CGV 31-08 + registre 09-08, facile à trouver
          Premier client : 1–2 semaines | Ticket : 600 diag + 4 900 pack | Dossier : `02_Niches_Deep_Dive/02_Ecommerce_Dropshipping_YouCan/00_INDEX.md`

Si vous avez déjà 3 clients dans une niche → restez-y 90j, ne switchez pas.
Si vous êtes à Casa/Rabat et avez un réseau PME → 09-08 (#3) est premium (8k–12k) mais 4–6 semaines.
Si vous avez un réseau MRE → MRE investisseurs (#5) mais besoin co-traitance FR.
```

**Règle :** ne choisissez pas 09-08 ou MRE en premier si vous n'avez pas encore vendu 3 packs #1 ou #2. Le cycle long tue la dopamine TDAH.

## Question 4 — Quel rythme TDAH tenir ?

```

```

## Question 6 — Quand pivoter ?

```
S6 (fin Traction) : avez-vous 2 packs signés ?
├─ OUI → Systemize (S7) : retainer + SOP + délégation comptable
└─ NON → Restez en Traction 2 semaines : doublez les DM comptables (5/jour), pas le contenu
         Relisez zones grises `02_Niches_Deep_Dive/*/08_Zones_Grises_Cas_Limites.md` — votre offre ou canal est à ajuster

S13 (fin Scale) : CA >35k/mois 2 mois consécutifs ?
├─ OUI → Scale : recrutez assistante 20% + 2e niche
└─ NON → Prolongez Scale 4 semaines avant d'ajouter une niche
```
