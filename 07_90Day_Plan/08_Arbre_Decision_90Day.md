# 08 — Decision Tree 90-Day (EN)

> Choose and keep ONE niche. Pivot only with data at J90, not with feelings at J21.

## Step 1 — Pick the niche (10 min)
```
Where do you already have 2-3 contacts?
├─ Freelancers / agencies (FR/EN, USD)      -> Niche 01  (fastest cycle)
├─ E-commerce YouCan / COD                  -> Niche 02  (highest volume)
├─ SMEs collecting data (09-08 / CNDP)      -> Niche 03  (highest ticket)
├─ Creators / influencers / infopreneurs    -> Niche 04
├─ MRE investors / foreign buyers           -> Niche 05  (trilingual edge)
├─ Auto-entrepreneurs scaling to SARL       -> Niche 06
├─ Startups / trademarks / OMPIC            -> Niche 07
├─ Cross-border tax / repatriation          -> Niche 08
├─ Importers / Office des changes           -> Niche 09
├─ MRE entrepreneurs                        -> Niche 10
└─ Digital nomads                           -> Niche 11
```
No contacts in any? Pick 01 or 02: easiest to find publicly (LinkedIn, Facebook groups, forums).

## Step 2 — Pick the channel (5 min)
```
Do you like writing/design?
├─ Yes -> LinkedIn (01) or SEO (02)
└─ No  -> Partnerships comptables (03) or Referral (06)
```
One channel for 90 days. Add a second only after the first produces one client.

## Step 3 — Keep or pivot (J30 / J60 / J90)
```
At J30: 100+ outreach and 0 diagnostics?
├─ Yes -> message problem. Rewrite the script, have 3 partners review it.
└─ No  -> continue.

At J60: diagnostics but 0 signed?
├─ Yes -> offer/pricing problem. Test a lower entry pack or a clearer deliverable list.
└─ No  -> continue.

At J90: signed 0-1?
├─ Yes -> pivot niche OR channel (one, not both).
└─ No  -> double down: same niche, same channel, next 90 days.
```
Pivot = ONE variable (niche or channel). Changing both resets everything to zero.
