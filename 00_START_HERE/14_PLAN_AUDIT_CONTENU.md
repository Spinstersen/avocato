## Règles d'audit (appliquer à CHAQUE fichier)

1. **Exactitude juridique** : chiffres, taux, délais, articles — vérifiés contre source officielle (sgg.gov.ma, tax.gov.ma, cnss.ma, cndp.ma, ompic.ma). Tout chiffre non vérifiable → marquer `[à vérifier]`, jamais laisser faux.
2. **Actualité loi 66.23** : toute citation « art. X loi 28-08 » doit être re-mappée dès que le texte consolidé est disponible au BO/SGG. Bannières déjà posées sur les 7 fichiers critiques (voir §0).
3. **Clarté pédagogique** : chaque concept technique a une explication « comme si tu n'étais pas avocat ». Chaque jargon = premier usage expliqué. Les QCM testent la compréhension, pas la mémorisation de numéros.
4. **Actionnabilité** : chaque fiche finit par « quoi faire concrètement lundi matin ». Si un fichier décrit sans prescrire → enrichir.
5. **Liens internes** : références croisées valides (audit 1832 liens du 23/08 = base ; les ~93 morts restants = templates désormais créés → re-vérifier et réparer).
6. **Format** : H1 unique, frontmatter léger, tableaux > paragraphes quand comparatif, exemples chiffrés type « cas Karim/Yassine/Léna ».
