# 12 — Ingénierie Fiscale Internationale & Shell : Dossier Maître

> **Dossier maître — Niche 12.** Objectif de ce dossier : **connaître les pratiques pour connaître les limites** — pas un mode d'emploi d'évasion. Chaque montage est traité en 4 temps : **pratique → limite légale → sanction → parade légale**. Juridictions retenues (3 max) : **Dubai / Estonia / US LLC**. Pack vendable **12 000 HT** (note substance + KYC + co-traitance comptable agréé + confrère étranger). Base : sgg.gov.ma, oc.gov.ma, rbe.ompic.ma, oecd.org, Bofip.

## TL;DR

*   **La ligne rouge :** optimisation = utiliser la loi telle qu'elle est écrite avec substance réelle ; évasion = simuler une substance qui n'existe pas. CGI art.208 abus de droit + art.213 prix transfert + BEPS action 6 (clause PPT) ferment la seconde porte.
*   **Substance = tout :** bureau réel + 2 salariés CNSS locaux + PV décisionnels sur place + compta locale. Sans les 4 → shell → requalification résidence effective Maroc + majoration 30%.
*   **Invisibilité n'existe plus :** registre BO OMPIC (Loi 43-05/12-18), CRS ~120 juridictions (Maroc opérationnel horizon 2028 — Forum mondial déc. 2025), FATCA 30%. Compte Dubai solde 500k = traçable.
*   **Chiffre d'arbitrage :** 1M bénéfice → SARL Casa seule 15% (150k) vs holding Dubai AVEC substance 9% (~90k + coûts substance ~70k/an) vs shell sans substance redressé 300k + pénalités. Le shell perd toujours à 5 ans.
*   **Offre :** Diagnostic International 1 200 HT → Note substance + KYC **Pack 12 000 HT** (co-traitance comptable agréé + confrère juridiction).

## Arbre « as-tu de la substance ? » (réponse en 2 min)

```
Ta société étrangère a-t-elle un bail réel au nom de la société ?
├─ NON → SHELL. Arrête ici : requalification quasi certaine.
│         Parade légale : SARL Casa seule ou attendre d'avoir la substance.
└─ OUI → 2+ salariés CNSS/équivalent local ?
    ├─ NON → SHELL fonctionnel. Risque : résidence effective requalifiée Maroc.
    └─ OUI → PV d'assemblées et signature contrats sur place ?
        ├─ NON → Substance partielle. Zone grise : documenter chaque décision.
        └─ OUI → Compta locale tenue + CA cohérent ?
            ├─ NON → Substance partielle. Renforcer avant tout flux significatif.
            └─ OUI → HOLDING SUBSTANTIELLE ✅
                      Vérifier encore : BO déclaré ? avoirs déclarés ? prix transfert benchmarkés ?
```

## Positionnement déontologique (à relire avant chaque mission)

1. Ce dossier répond à « où est ma ligne rouge », jamais « comment ne pas être vu ». La question « invisible » est fausse : BO + CRS + SWIFT rendent tout visible.
2. Tout diagnostic renvoie : diagnostic 45 min payant + comptable agréé pour le chiffrage + confrère dans la juridiction cible.
3. Devoir d'information art.59 Loi 28-08 : information doctrinale, pas consultation. Secret professionnel art.36.
4. Si le client insiste sur un montage shell après mise en garde écrite : refuser la mission (risque complicité fraude fiscale + atteinte déontologie barreau).
