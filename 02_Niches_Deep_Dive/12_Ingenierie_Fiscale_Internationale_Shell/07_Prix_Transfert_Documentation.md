# 07 — Prix de Transfert : Documentation CGI art.213 (Master File / Local File / CbCR)

> **Pratique → limite → sanction → parade.** Concept §15 du glossaire (`00_START_HERE/03_Glossaire_12_Concepts_Cles.md`). Sources : sgg.gov.ma CGI art.213 II, art.214-III (LF 2021), art.234 bis (APP, LF 2015), LF 2020 CbCR ; Principes OCDE BEPS action 13.

## TL;DR

*   **Règle :** entre sociétés liées transfrontalières, prix = pleine concurrence (ce qu'auraient payé des indépendants). CGI art.213 II rapporte au résultat marocain tout bénéfice indirectement transféré.
*   **Documentation obligatoire** (CGI art.214-III, LF 2021) si transactions intragroupes transfrontalières ET CA ≥50 MMAD ou actif brut ≥50 MMAD : master file + local file, format électronique, à produire en cas de contrôle.
*   **CbCR** (LF 2020) : groupes CA consolidé ≥8,136 MMDH (~750M EUR) — dépôt DGI dans les 12 mois de la clôture.
*   **Sanction :** redressement des bénéfices transférés + majorations droit commun + amende défaut documentation ~0,5% (à vérifier LF en vigueur).
*   **Sécurisation :** APP avec la DGI (art.234 bis) — méthode validée pour 4 exercices.

## Qui est concerné (même à taille humaine)

| Situation | Concerné ? |
|---|---|
| SARL Casa facture management fees à sa holding Dubai | OUI dès le premier dirham si liens ≥50% — documentation exigible aux seuils, benchmark exigé AU CONTRÔLE dans tous les cas |
| SARL Casa vend services à la société du conjoint en France | OUI (lien de dépendance de fait) |
| Freelance SARL facture clients indépendants | NON (pas de liens) |
| Groupe familial multi-pays même actionnaire | OUI |

**Point clé diagnostic :** l'obligation de PRIX DE MARCHÉ s'applique dès qu'il y a liens + transaction, sans seuil. Le seuil 50 MMAD ne concerne que la FORME de la documentation.

## Les 5 méthodes OCDE acceptées

1. **Prix comparable sur marché libre (CUP)** : référence directe à un prix de marché comparable — la plus solide.
2. **Prix de revente minoré** : prix revente − marge du revendeur.
3. **Coût majoré** : coût + marge d'un prestataire indépendant.
4. **Partage des bénéfices** : répartition selon fonctions/actifs/risques.
5. **Marge nette transactionnelle (TNMM)** : comparaison de ratios de marge avec comparables.

**Cas type vault :** dev senior facturé 500 DH/j à la holding quand le marché local est à 800 DH/j → 300 DH/j × jours × IS = redressement + majoration 30% sur exercices non prescrits.

## Contenu minimal d'un dossier défendable (même sous les seuils)

```
1. Organigramme groupe + bénéficiaires effectifs (croisé registre BO)
2. Description fonctions/actifs/risques de chaque entité (FAR analysis)
3. Liste transactions intragroupes chiffrée par année
4. Méthode retenue + JUSTIFICATION
5. Benchmark : 3-5 comparables sourcés (bases publiques, offres, barèmes)
6. Contrats écrits intragroupes signés AVANT les flux
7. Factures cohérentes avec contrats et benchmark
```

## Procédure — sécuriser en 4 étapes

1. **Cartographier** les flux intragroupes (qui facture quoi à qui, devises, volumes).
2. **Benchmarker** chaque catégorie de transaction AVANT facturation (écrit, daté, sourcé).
3. **Contractualiser** : conventions intragroupes écrites (management fees, licence IP, prêt) alignées sur le benchmark.
4. **Si volumes significatifs** : déposer une demande d'APP (art.234 bis) via comptable agréé — méthode verrouillée 4 exercices.

## Sanctions

| Manquement | Conséquence |
|---|---|
| Prix non conformes | Bénéfices transférés rapportés au résultat Maroc + IS + majoration 30% (+100% caractérisé) |
| Documentation absente au contrôle | Amende ~0,5% des transactions concernées (à vérifier LF) + présomption défavorable |
| CbCR manquante (>8,136 MMDH) | Sanctions déclaratives DGI |
| Ajustement corrélatif mal géré | Double imposition (d'où clauses d'ajustement corrélatif conv. FR-MA) |

## Phrase diagnostic

> « Tant que vous facturez votre propre société étrangère, chaque facture est un prix de transfert. Le benchmark écrit avant facturation coûte quelques milliers de dirhams ; son absence au contrôle coûte l'IS évité + 30%. »
