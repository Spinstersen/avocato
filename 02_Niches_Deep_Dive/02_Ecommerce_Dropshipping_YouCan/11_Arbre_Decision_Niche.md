# 11 — Arbre Décision (02_Ecommerce_Dropshipping_YouCan)

> Réf : `00_START_HERE/03_Glossaire_12_Concepts_Cles.md` §01-§12 — pas de PE en e-commerce pur (pas de lieu fixe >6m), ordre CGV → 09-08 → CMI → Marque.

## Ordre procédural : CGV d'abord, pas le statut

Vendre en COD sans CGV conformes Loi 31-08 = litige au tribunal de commerce sans preuve écrite art.443 §11. D'où : **CGV 31-08 → Registre 09-08 → CMI/Dotation → Marque 35**.

```
[Q1] CGV 31-08 publiées + preuve consentement ? §11 / Loi 31-08
 ├─ NON → Risque tribunal commerce → Rédiger CGV + checkout YouCan + archivage commande §10-§11
 └─ OUI → [Q2] Collecte données (email/tel) → registre 5 col art.14 ? §06
           ├─ NON → Déclaration CNDP en ligne 30j §06 avant d'encaisser
           └─ OUI → [Q3] Encaissement CMI + rapatriement/dotations ? §03 + §12
                     ├─ COD espèce → versement 48h + déclaration CMI
                     └─ Stripe/PayPal → dotation 15k SaaS §03 + compte convertible §12
                          └─ [Q4] Marque OMPIC classe 35 déposée ? §05
                               ├─ NON → Recherche antériorité + dépôt 1 200 DH/classe 72h
                               └─ OUI → Surveillance opposition 2 mois §05
```

## Tableau décision — 4 branches

## Cas chiffrés

* **Amine, YouCan COD 800k CA commerce, pas de CGV, pas de registre** : AE impossible (>500k) §09 → SARL IS 15% si bénéfice <300k → régularisation : CGV 31-08 (3 500 DH) + registre art.14 + déclaration CNDP 30j §06 ; sans CGV litige 20k : perdu faute preuve art.443 §11.
* **Sara, dropshipping Shopify, Stripe US, ads Meta 12k/an** : Dotation 15k §03 → Meta 12k OK (reste 3k) ; Shopify 29$/m = 348$ → OK. Si besoin 22k → dépassement 7k = infraction → passer par compte devise alimenté virement étranger §12.
* **Boutique "CasaGlow" 50 cmd/j, marque non déposée classe 35** : Concurrent dépose CasaGlow 35 → vous perdez nom après 2 mois opposition §05 → coût rebrand 80k + stock ; dépôt préventif 1 200 DH évite 80k.

## Erreurs / pièges

* **Piège CGV** : Copier CGV France sans Loi 31-08 Maroc → clause abusive → nullité + amende DGCM.
* **Piège 09-08** : Base 5 000 emails sans registre → contrôle CNDP sanction 2023-045 mise en demeure 45j §06 (08_Jurisprudence/01:5-10).
* **Piège CMI** : Encaisser COD 300k en espèce sans versement banque 48h → blocage CMI + soupçon blanchiment.
* **Piège Marque** : Déposer seulement classe 35 pour app mobile → classe 09/42 non protégée → concurrent dépose app et vous bloque §05.
* **Piège Statut** : Rester AE à 620k commerce 2 ans → radiation Loi 114-13 + redressement IS 15% + IR 38% §09.
* **Piège TVA** : Vendre à client FR en EUR sans facture art.144 §04 → pas de preuve export → TVA 20% redressée malgré Stripe.
* **Piège 183j** : Gérant YouCan 210j Casa sans attestation DGI §01 → IS mondial §09 non anticipé + carte 1 an §08 oubliée.

## L'arbre comme outil d'entretien, pas comme automate

Pour e-commerce YouCan, l'arbre ne commence pas par AE vs SARL mais par CGV et 09-08 — le statut §09 vient après la conformité vitrine. Pas de PE §02 en dropshipping pur (pas de bureau >6m à l'étranger), donc pas de branche PE. Chaque branche renvoie à une mission avec convention provision 50% §10 et preuve DOC art.230 §11. Vérifiez IGOC et Loi 31-08 à J-0.
