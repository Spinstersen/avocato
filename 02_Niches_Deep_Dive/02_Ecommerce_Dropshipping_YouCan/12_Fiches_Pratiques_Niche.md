# 12 — Fiches Pratiques + Checklist (02_Ecommerce_Dropshipping_YouCan)

## Checklist 12 points — E-commerce / Dropshipping YouCan

*   [ ] CGV Loi 31-08 art.36-38 droit rétractation 7j (protection consommateur) — rédiger CGV FR/AR avec identité vendeur ICE/RC + prix TTC + livraison + 7j rétractation sans motif, remboursement 15j, clause pénale 10% DOC art.264 → voir Glossaire §11 + Loi 31-08
*   [ ] Registre Loi 09-08 5 colonnes art.14 (CNDP) — dès 1 email/tél collecté : traitement prospection / finalité commande-WhatsApp / base consentement non pré-cochée / durée 3 ans / destinataires YouCan+livreur, déclaration CNDP 30j → voir Glossaire §06
*   [ ] Bannière cookies & consentement (CNDP délib.40-22 / Loi 09-08) — bandeau non pré-coché + refus = pas de dépôt, preuve consentement loguée, politique confidentialité lien footer, mise en demeure 45j si non-conforme → voir Glossaire §06
*   [ ] Facture conforme CGI art.144 + TVA 20% Maroc — mentions obligatoires ICE/RC/IF + numérotation + TVA 20% (pas exon art.92 si client Maroc), conservation 10 ans, amende 10k si facture incomplète → voir Glossaire §04
*   [ ] Contrat Monétique CMI / MoPay / Wafacash — dossier banque : RC + contrat YouCan + CGV 31-08 + registre 09-08 → TPE virtuel 7j, commission 1,5-2,8% + retenue Rolling 10% 180j → voir Glossaire §03 (dotation)
*   [ ] Marque OMPIC Loi 17-97 classes 35+9+42 (1 200 DH/classe) — recherche antériorité directompic.ma 2h, dépôt en ligne accusé 72h, publication 4-6 mois + opposition 2 mois art.148, protection 10 ans, premier déposant = propriétaire art.133 → voir Glossaire §05
*   [ ] Transfert hors Maroc art.43-44 Loi 09-08 (AWS/Shopify/Mailchimp) — hébergement US = transfert → clauses contractuelles types CNDP + info clients + registre colonne destinataires, autorisation CNDP si données sensibles → voir Glossaire §06
*   [ ] Contrat sous-traitant art.24 Loi 09-08 (YouCan, livreur, pixel Meta) — contrat écrit : finalité + durée + sécurité + sous-traitant ne traite que sur instruction, audit possible, modèle CNDP → voir Glossaire §06
*   [ ] OMPIC création AE 200k/500k vs SARL 10k capital 7-14j (Loi 114-13/5-96) — AE service 200k commerce 500k IR 1% commerce/2% service, SARL IS 15% <300k bénéfice CRI ~2 000 DH → voir Glossaire §09
*   [ ] Dotation e-commerce 15 000 DH/an IGOC 2024 — payer Shopify/Stripe/Meta Ads via banque RC + factures, carte dotée 15k en 10 min, voyage 100k/an en sus, dossier Office RC1 30j si > plafonds → voir Glossaire §03
*   [ ] Provision 50% art.30 Loi 28-08 + convention honoraires — convention préalable HT/TVA 20%, provision 50% Yousign avant rédaction CGV, délai 7j après provision + accès YouCan → voir Glossaire §10
*   [ ] Compte convertible 48-72h + mentions légales site — ouverture RC + CGV + registre → compte convertible crédité par CA local (pas rapatriement 30j), footer : RC/ICE/IF/CGV/09-08/politique retour 7j → voir Glossaire §12

> **Légende :** Chaque case = Concept (base légale) — procédure 1 ligne + chiffre 2025 + renvoi Glossaire. Ne cochez pas sans avoir lu le §.

## Fiche comme mémoire externe, pas comme script de vente

Ne vendez pas "CGV + registre" comme un pack générique. Cette fiche est une mémoire pour ne rien oublier chez le e-commerçant YouCan : CGV 31-08 7j (remboursement 15j), facture art.144 ICE obligatoire, registre 5 colonnes avec base consentement, bannière non pré-cochée, transfert AWS art.43-44 avec CTT, marque 35+9+42 à 1 200 DH/classe opposition 2 mois, CMI qui bloque sans registre, dotation 15k pour payer Shopify US. Chaque case = base légale + chiffre + procédure + renvoi CNDP/OMPIC. Contrôle CNDP 2023-045 (50 cmd/j sans registre) = mise en demeure 45j réelle. L'ordre est CGV → facture → registre → bannière → transfert → CNDP → marque → CMI.
