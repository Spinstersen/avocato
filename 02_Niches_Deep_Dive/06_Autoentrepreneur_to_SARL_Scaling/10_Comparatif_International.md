## 3 cas chiffrés comparatifs — bascule AE → SARL

**Cas A — Freelance service 190k DH CA 12m (<200k), 210j Casa, client 100% Paris, charges 20k :**
AE 2% = **3 800 DH** net ≈166k. SARL 10k capital : bénéfice 170k → IS 15% = **25,5k + CNSS 21% sur 80k salaire =16,8k** → total 42k → **AE gagne 38k** → rester AE 12 mois, préparer **transformation à 220k CA** (dès dépassement). France même CA 17,4k€ (<77k€) : micro 35% =6k€ vs SARL 15% 42,5k€ — micro gagne encore. **Écart Maroc-France AE : 2% vs 35% = 57k DH d'écart** à 190k.

**Cas B — E-commerçant 520k DH CA commerce (>500k), bénéfice 150k DH, client Maroc 60% :**
AE radié 48h obligatoire (dépassement 2 ans = radiation + redressement IS 15% +30% pénalités). SARL IS 15% = **22,5k + TVA Maroc 20% sur 312k =62,4k** vs AE 1% =5,2k → **saut 80k** → mais AE illégal. France 520k DH =47,6k€ commerce (<188k€) → micro encore possible 35% =16,6k€ → **France scale 3× plus tard**. **Leçon MA : anticiper à 450k, pas à 520k.** Bascule pack 4 900 HT 7-14j + nouveau ICE.

**Cas C — Scale 800k DH CA service, bénéfice 350k DH, dividende 100k vers associé Paris (40j MA) :**
AE impossible. SARL Maroc IS : 300k×15%=45k + 50k×20%=10k → **55k IS**. France SASU même bénéfice 32k€ (≈350k DH) : IS 42,5k€×15%=6,3k€ + reste 25% = **~9k€ (≈98k DH)** → **Maroc gagne 43k DH** (PLF). Dividende 100k → FR : **10% =10k** via 5000-F + attestation DGI 30j + devise MRE 72h vs **30k PFU** sans → **économie 20k**. Total économie vs FR : 43k+20k = **63k DH/an**. Procédure : radiation AE 48h → CRI 7-14j → facture art.92 0% si export → SWIFT 30j.

## Verdict AE → SARL scaling

*   **Seuil bascule** : Maroc **200k service / 500k commerce 12m glissants** (pas année civile) — à 180k/450k, lancer **pack SARL 4 900 HT 7-14j** (5 500 HT +2k débours). France **77k/188k** → scale 4× plus tard mais **35% charges dès 1€** → AE Maroc plus rentable <200k.
*   **Coût bascule** : **Radiation 48h + création ex nihilo** (pas de transformation) — prévoir coupure banque/CMI 10j. Provision **50% Loi 28-08 art.30** avant dépôt CRI.
*   **Après bascule** : IS **15% <300k bénéfice** (vs FR 15% <42,5k€) + CNSS **21%** vs URSSAF **45%** → SARL Maroc avantagée si bénéfice >100k. Déclenchement **TVA 20%** client MA / **0% art.92** client FR-US (3 cond. SWIFT 30j) → sinon redressement 20%×CA.
*   **Procédure crédit art.27 :** Dividende SARL nouveau → FR/BE/ES : retenue **10% FR /15% BE /10% ES** via **attestation DGI résidence art.4 (30j, 183j/foyer §01) + formulaire 5000-F Bofip avant virement** + compte devise MRE 72h → **15k économisés /100k bénéfice** crédités IR étranger. Sans 5000-F = double imposition 15k+25k. → §09 §07 §04

## Interactions

*   §09 AE plafond + §01 183j : 210j + AE 220k = radiation + IS mondial 15% — double sanction si oubli.
*   §09 → §04 TVA + §03 Rapatriement : AE non assujetti → SARL = TVA 20% ou 0% art.92 conditionnée à SWIFT 30j → compte convertible 48h §12.
*   §10 Provision 50% + §11 DOC art.443 : convention scaling signée avant radiation AE — sinon contrat >10k sans preuve + impayé 60%.
*   §02 PE 6m : gérant SARL Casa + commercial Paris signataire 7 mois = PE FR 25% malgré bascule — à tester avant embauche.
*   §06 09-08 + §05 OMPIC : scaling e-commerce = registre 5 col. + dépôt marque 35/9/42 avant pub — sinon 10k-300k + rebrand.

## Procédure crédit art.27 + 5000-F (détail scaling)

1. **Suivi CA** : alerte 180k service /450k commerce 12m glissants — lancer devis SARL (§09) avant radiation 2 ans.
2. **Radiation AE 48h** ae.gov.ma + **CRI 7-14j** (statuts 10k capital, RC/ICE) + **provision 50% art.30** avant dépôt (§10).
3. **TVA bascule** : AE non assujetti → SARL TVA 20% MA ou 0% art.92 si export FR-US + SWIFT 30j (§04 §03) — prévoir 10j coupure CMI.
4. **Attestation DGI 30j** (183j/foyer §01) + **5000-F Bofip** visé avant 1er dividende SARL → retenue **10% FR /15% BE** vs 30% PFU → **15k économisés/100k** (Cas C) (§07).
5. **Compte** : nouveau ICE = nouveau compte convertible 48h (résident) / devise MRE 72h (§12) — ne pas réutiliser compte AE perso.

## Lecture comparative — pourquoi comparer sans copier

Le 200k service /500k commerce Maroc 12m glissants n'est pas le 77k/188k France année civile — période et assiette diffèrent. Le 2% AE sur CA brut n'est pas le 15% IS sur bénéfice SARL (charges déductibles). La radiation 2 ans Maroc ≠ radiation France ; le pack 4 900 HT 7-14j avec nouveau RC/ICE + CMI à refaire n'est pas la transformation SASU 1 000€ 7j. Expliquez au client à 520k pourquoi il doit scaler à 450k anticipé et pourquoi TVA 20% s'active dès SARL même à 300k bénéfice.
