# 02 — Dotation Voyage 100,000 DH/an + 45% IS

## Plafond 2024

*   **100,000 DH/an/pers** (adulte) + **45% IS payé** l'année précédente (si SARL). Enfant <12 ans 50%.
*   **Cumul:** Famille 4 adultes = 400k + 45% IS si gérant.
*   **Inclus:** Billets, hôtel, dépenses étranger via carte/billet.

## Procédure banque (15 min)

*   Passeport + billet aller (ou attestation voyage) + CIN → banque → débit compte DH → délivrance devises (cash 2k€ max + carte). Taxes: commission 2%.

## Cas nomad Lena (Berlin→Agadir)

*   Lena veut 100k pour 3 mois Europe → banque Attijari: passeport + billet Berlin → 100k DH = 9,100€ → carte voyage.

## Erreur

*   Dépasser 100k sans justif IS → blocage + déclaration Office.
*   Utiliser dotation voyage pour payer SaaS → détournement → amende Office.

## Mission

*   Diagnostic dotation 900 HT: quelle dotation pour quel besoin.
