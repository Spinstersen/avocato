# 05 — Import / Export & Rapatriement 30j (IGOC Titre II)

## Export services (freelance/e-com) — cœur

*   **Rapatriement 100% 30j** à compter encaissement devises sur compte étranger (Wise) → doit arriver compte convertible Maroc 30j.
*   **Justif 30j:** contrat + facture + avis SWIFT (voir `07_Obligations_Rapatriement_Justificatifs.md`).

## Import

*   **Domiciliation 90j:** Facture import domiciliée banque 90j avant paiement → paiement via dotation import.

## Cas Salma ecom (YouCan 30k/mois, fournisseur Chine 10k/mois)

*   Export 30k → rapatrie 30k 30j → Import 10k → domiciliation + paiement → net 20k.

## Délais

| Flux | Délai | Sanction si > |
|---|---|---|
| Export rapatriement | 30j | Amende 3k-30k |
| Import domiciliation | 90j | Blocage paiement |

## Checklist

*   [ ] Contrat export signé avant encaissement
*   [ ] Facture domiciliée 90j si import
*   [ ] Avis SWIFT gardé
*   [ ] Banque justif 30j
