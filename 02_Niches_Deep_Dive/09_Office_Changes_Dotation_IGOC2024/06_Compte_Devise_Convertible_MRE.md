# 06 — Compte Devise / Convertible / MRE (IGOC Titre I)

## 3 Comptes (choisir 1)

| Compte | Qui | Alimentation | Débit | Avantage |
|---|---|---|---|---|
| **Convertible DH** (résident) | Freelance SARL Casa | Devises rapat 30j → converti DH mais traçable | DH + devises (dotation) | Rapatriement légal 30j |
| **Devise MRE** (non-résident MRE) | Karim MRE Paris | Devises étranger + loyers Maroc | Devises + DH | Pas de blocage, libre transfert |
| **Devise résident** (nomad résident >183j) | Lena nomad 210j | Devises rapat | Devises | Comme convertible mais devises gardées |

## Ouverture (banque 48h)

*   **Convertible:** RC SARL + statut + CIN + contrat export → Attijari/CGP 48h.
*   **MRE:** Passeport + titre séjour étranger + justificatif adresse étranger + RC si SARL → 72h.
*   **Devise nomad:** Carte séjour 1 an `08_Fiscalite.../04_Statut_Juridique_Nomad_Carte_Sejour.md` + RC.

## Cas Yassine (convertible)

*   Yassine SARL → ouvre convertible Attijari 48h → Wise $5k → convertible 50k DH → justif 30j OK.

## Cas Karim MRE (devise MRE)

*   Karim ouvre devise MRE BMCE Paris (via succursale) → loyers Casa 10k → transfert Paris libre (Office 0 si <10M/an).

## Erreur

*   Compte perso DH pour rapat 5k$ → banque bloque J+30 → redressement Office.

## Checklist ouverture

*   [ ] RC + statut + CIN/passeport
*   [ ] Contrat export
*   [ ] 48-72h délai
*   [ ] Activer dotation 15k/100k sur carte liée

## Analyse doctrinale et raisonnement juridique — Comptes devises

**Pourquoi trois comptes distincts** : Le compte convertible (résident) matérialise le rapatriement : les devises y transitent avant conversion en DH, traçable pour l'Office. Le compte en devises MRE (non-résident) préserve la liberté de transfert du MRE qui vit à l'étranger (pas de rapatriement obligatoire). Le compte en devises résident (nomade >183j) est une tolérance pour le résident qui facture en devises et veut les garder en devises.

**Raisonnement** : Le choix du compte détermine le régime : se tromper (rapatrier 50k $ sur compte perso DH) déclenche un blocage J+30 pour défaut de justif, alors que le même flux sur convertible avec contrat+facture 30j passe sans Office. L'ouverture exige RC + statut + justificatif export — la banque n'ouvre pas un convertible sans preuve d'activité export.
