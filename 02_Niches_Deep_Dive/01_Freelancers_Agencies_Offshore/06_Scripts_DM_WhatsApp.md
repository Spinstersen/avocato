# 06 — Scripts DM et WhatsApp pour la niche freelance offshore

## 1. La règle fondamentale

> **L'avocat ne DM jamais spontanément un prospect.** Il répond aux sollicitations reçues.

Tout DM spontané est du démarchage, interdit par la Loi 28-08.

## 2. Le script de réponse à un DM LinkedIn entrant

```
Bonjour [nom],

Merci pour votre message. Votre situation est typique des
freelances marocains qui facturent à l'étranger — vous avez
besoin de sécuriser votre statut et vos contrats.

Je propose un diagnostic de 45 min à 600 DH HT (convention
d'honoraires écrite conformément à l'art. 30 Loi 28-08).
À l'issue, je vous remets une note de risques écrite et un
devis pour la mission à mener. Le diagnostic est déduit de
la mission si vous signez dans les 14 jours.

Pour réserver un créneau, vous pouvez :
- Choisir sur [Calendly link]
- Me renvoyer ce message avec vos disponibilités

Bien à vous,

[Nom]
Avocat au barreau de [Ville]
```


## 6. Le script de demande de feedback

```
Bonjour [nom],

J'espère que la mission [type] vous convient. Si vous avez
2 minutes, je vous serais reconnaissant de me dire ce qui
vous a plu le plus. Cela m'aide à améliorer mon offre.

Bien à vous,
[Nom]
```

## 7. Le script de demande de referral

```
Bonjour [nom],

Suite à la mission [type], si vous connaissez 1-2 autres
freelances offshore qui ont le même type de problème, je
peux leur envoyer la même checklist gratuitement. Vous me
mettez en contact WhatsApp ?

Pour chaque recommandation, j'offre un diagnostic gratuit
(valeur 600 DH HT) au filleul.

Bien à vous,
[Nom]
```

## 8. Le script de refus poli

```
Bonjour [nom],

Merci pour votre message. Votre demande relève d'un domaine
qui sort de mon champ d'intervention (droit pénal général,
droit de la famille, etc.).

Je vous recommande de vous adresser à un confrère spécialisé.
Vous pouvez consulter l'annuaire du barreau de [Ville] à
[lien].

Bien à vous,
[Nom]
```

## 9. Les phrases à éviter

| Phrase à éviter | Reformulation sobre |
| :--- | :--- |
| « Je suis le meilleur avocat pour freelances » | « J'accompagne les freelances offshore marocains » |
| « Contactez-moi maintenant » | « Pour réserver un créneau : [Calendly] » |
| « DM-moi pour un audit gratuit » | « Pour un diagnostic à 600 DH HT : [lien] » |
| « Vous gagnerez votre affaire à 100% » | « Voici les étapes juridiques de votre affaire » |

## 10. FAQ

**Q : Puis-je répondre à un DM par WhatsApp ?**
R : Oui, si le prospect a fourni son numéro. Sinon, continuer sur LinkedIn/email.

**Q : Combien de temps pour répondre ?**
R : 24-48h maximum. La réactivité est un critère d'achat majeur.
