# 15 — Portage vs AE vs SARL décortiqué (freelance offshore)

> Le choix de statut expliqué de bout en bout : mécanique, social, fiscal, change, coûts, calendrier. Pas de réponse universelle — une simulation datée avec le comptable. Vérifié 07/09/2026 — AE loi 114-13 + CGI (plafonds 200k services / 500k commerce, radiation après 2 ans consécutifs, retenue 30% au-delà de 80k/client LF2023 à ouvrir), IS 20%/35%/40%, change 90j/150j IGOC 2026.

## 1. Les trois voies — mécanique complète

**AE.** Immatriculation RNAE rapide, pas de comptabilité complète mais factures + relevés tenus, déclaration simplifiée, 1% services / 0,5% commerce + retenue client 30% au-delà de 80k DH/client. Idéal <150k services sans charges ni salarié, client unique non problématique. Limites : plafonds, pas de charges déductibles, pas de TVA récupérée, pas de salarié, image faible pour gros clients, radiation si dépassement 2 ans.

**SARL/SARL-AU (loi 5-96).** Statuts + RC/ICE/TP/CNSS + compte pro (dont devise), comptabilité complète, IS sur bénéfice + TVA + dividendes datés (RAS 11,25% 2026 → 10% 2027). Idéale dès charges réelles (sous-traitants, SaaS, loyer), équipe, volume >200k, besoin de crédit/banque. Coût : création + comptable mensuel + audit selon seuils.

**Portage salarial / contrat local étranger.** Le portage déplace le contrat (salaire + bulletins + protection) mais jamais la résidence fiscale ni la source ni le change si travail depuis le Maroc. Utile pour mission FR durable sans créer de société, avec certificat de détachement si ≤3 ans (conv. sécu 22/10/2007). Inutile pour facturer en masse sans substance.

## 2. Comparatif encyclopédique en 9 points

Objet : simplicité, plafonds, charges, TVA, social/retraite, banque/crédit, image client, changement d'échelle, risque. Exemple : 400k DH/an avec 100k de charges et 2 sous-traitants = AE intenable (plafond + pas de charges + sous-traitance non portée) → SARL gagnante malgré l'IS, car base = 300k bénéfice + TVA récupérée + registre propre.

## 3. Erreurs fatales décortiquées

Rester en AE à 350k « pour payer 1% » → radiation + requalification + perte charges. Facturer via LLC/Wise sans SARL → change continu + IR mondial (`08/18`). Salarié déguisé en freelance (lien de subordination, horaires, matériel client) → requalification prud'homale + CNSS. Compte courant comme paie → avance déguisée.

## 4. Protocole décision 30 min + bascule 6 mois

Diagnostic (flux 12 mois, charges, clients, jours, résidence) → simulation 3 scénarios avec comptable (coût global + couverture) → décision écrite datée → si bascule : statuts + immatriculations + avenants clients + compte devise + clôture RNAE + registre + calendrier AG (`06` + `16` Pack Bascule). Revue annuelle à chaque LF.
