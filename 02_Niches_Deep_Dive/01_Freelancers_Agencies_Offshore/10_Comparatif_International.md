## 3 cas chiffrés comparatifs — freelance 180k Maroc vs France

**Cas A — Freelance solo 180k DH CA service (~16,5k€), 210j Casa, sans PE :**
Maroc AE 2% = **3 600 DH (330€)** IR libératoire, net ≈16 170€. France micro 12,3%+23% = **6 000€** prélèvements, net ≈10 500€. **Économie Maroc = 5 670€ /an**. TVA 0% des deux côtés si export tracé art.92/262. Au-delà 200k DH → AE radié → passage SARL 7-14j (5 500 HT + 2 000 DH CRI).

**Cas B — Agence 600k DH CA, 300k DH bénéfice, closer Paris 7 mois :**
Sans PE : IS Maroc 15% = **45k DH**. Avec PE requalifié (commercial qui signe à Paris) : IS Maroc 45k + IS France 25% sur 150k rattaché = **37,5k** → total 82,5k + pénalités. **Surcoût PE = 37,5k DH/an** → solution : closer sans pouvoir de signer ou filiale/portage 8%. → §02 §07

**Cas C — Dividende 120k DH SARL Casa vers MRE Paris (non-résident 40j MA, foyer FR) :**
Sans convention : IS MA 15k (sur 100k bénéfice) + IR FR 30k = **45k**. Avec Conv. 29 mai 1970 art.27 : retenue 10% = **12k** + attestation DGI + formulaire **5000-F** avant virement + compte **devise MRE 72h** (IGOC). Économie = **18k DH**. BE même cas = 18k (15%) vs 30k sans. Procédure : DGI attestation résidence 30j → banque → 5000-F → virement SWIFT. → §07 §12 §03

## Verdict freelance offshore

*   **<200k DH service** : AE Maroc imbattable (2% vs 35% FR) — mais bloqué à 200k. Anticiper SARL dès 180k CA 12m glissants.
*   **200k-1M DH bénéfice** : SARL Maroc IS 20 % (LF 2026)plus large que FR 15% <42k€ ; avec export art.92 bien documenté (SWIFT 30j + mention facture art.144), **économie 20-25k DH / tranche 300k** vs France.
*   **Procédure crédit art.27 (Conv. 29 mai 1970 BE 1972 ES 1985) :** 1) attestation résidence DGI (30j, passeport+bail+RC) 2) formulaire **5000-F** (Bofip) signé DGI → banque FR 3) crédit IS Maroc sur IR FR ligne 2047 → **économie 15k sur 100k bénéfice** exemple §07. Sans 5000-F, banque FR retient 30% PFU.
*   **Carte séjour :** Touriste 90j max (180j/an) interdit de gérer SARL ; à 210j → carte 1 an 200 DH obligatoire (30j préfecture) vs Talent FR 4 ans 300€ si CA >40k€. → Glossaire §01 §02 §08 §09

## Interactions (chaîne causale §01→§09→§02→§07→§03→§04→§12→§10)

*   §01 Résidence 183j : 210j Casa = résident mondial → AE 200k plafond s'applique (§09) + carte 1 an §08.
*   §02 PE : Même résident, PE Paris 7 mois = IS FR 25% ponctionne avant crédit §07.
*   §07 Convention art.27 : PE détermine où taxer + montant crédit ; sans attestation = double imposition.
*   §03 Rapatriement 30j + §04 TVA art.92 : condition de l'exonération — SWIFT = preuve pour banque + compte convertible §12.
*   §12 Compte : convertible (résident) vs devise MRE (non-résident) → erreur = blocage dividende 10% FR.
*   §10 Provision 50% Loi 28-08 art.30 : convention FR fait foi + clause paiement devises avant facturation >10k DOC art.443 §11.

## Procédure crédit art.27 + 5000-F (détail niche freelance)

1. **Avant facturation** : convention FR fait foi + clause TVA art.92 + paiement devises 30j (§10 §11) — sinon preuve art.443 manquée.
2. **Attestation résidence** : dépôt DGI (passeport + bail 12m + RC + ICE), délai **30j**, 0 DH — indispensable pour activer Conv. 29 mai 1970 art.4 (§01 §07).
3. **Formulaire 5000-F** : télécharger Bofip `impots.gouv.fr` 5000-SD, faire viser par DGI Maroc, remettre à banque FR **avant** virement dividende — sinon retenue 30% PFU (§07).
4. **Crédit** : reporter IS Maroc 15k sur déclaration FR 2047 ligne crédit d'impôt — économie **15k/100k bénéfice** (exemple Cas C). Conserver 10 ans (§03).
5. **Compte** : si résident 210j → **convertible 48h** ; si 40j → **devise MRE 72h transférable** (§12) — erreur = blocage SWIFT.

## Lecture comparative — pourquoi comparer sans copier

Comparer Maroc/FR/BE n'est pas transposer. L'AE 200k/500k Maroc (IR 2%/1% sur CA brut) n'est pas le micro 77k FR (12,3%+23% URSSAF sur CA brut) — bases et plafonds diffèrent. Le 15% IS Maroc sur **bénéfice après charges** (bureau Casa 3k DH) n'est pas le 15% FR sur 42,5k€ de bénéfice comptable FR avec charges Paris ×4. Le comparatif sert à expliquer au freelance MRE pourquoi sa SASU 1€ ne s'applique pas au Maroc et à justifier la SARL marocaine malgré l'Apostille 14j.
