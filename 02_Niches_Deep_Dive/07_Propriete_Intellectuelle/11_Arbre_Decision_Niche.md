# 11 — Arbre Décision (07_Propriete_Intellectuelle)

> L'arbre protège **l'actif**, pas la procédure. Sa première sortie n'est pas un dépôt — c'est parfois « ne déposez pas encore » (recherche, titularité, modèle réel). Ordre canonique : quoi (signe) → à qui (titulaire) → où (pays) → comment (classes) → quand (fenêtre).

## L'arbre

```
QUEL ACTIF ? (un signe = une question distincte)
├─ Le NOM / LOGO de l'activité
│   → MARQUE (17-97). Question qui suit : qui la détient ?
│     (crée en interne, ou par un freelance?)
│   ├─ Titulaire interne / société → OK, branche classes
│   └─ Créé par un freelance SANS cession écrite (2-00 art.9)
│        → D'ABORD la cession, PUIS le dépôt au nom de la
│          société — sinon vous déposez un signe pas à vous.
├─ Le CODE / la formation / le design (œuvre)
│   → DROIT D'AUTEUR (2-00) : pas de dépôt d'enregistrement
│     « comme une marque » ; la question est la PREUVE
│     d'antériorité (registre horodaté) + la CESSION écrite.
├─ L'INVENTION technique
│   → BREVET (texte distinct) — expert + coût : en parler
│     honnêtement ; le secret industriel est souvent la vraie
│     réponse. (Hors pack standard : mission spécialisée.)
└─ Le NOM DE DOMAINE / @handle
    → ce n'est PAS une marque ; aligner dépôt + DNS le même
      jour (08, zone 4).

OÙ protéger ? (territorialité — 10/§4)
├─ Client 100 % Maroc → OMPIC, et on s'arrête là (le reste
│   est du budget qui dort)
└─ Export/levée → Maroc D'ABORD (dépôt de base), puis
    ├─ 1 pays ciblé → dépôt national dans ce pays
    └─ ≥ 2-3 pays → MADRID (Protocole ; Maroc membre 1999 ;
       office d'origine = OMPIC) — mais USA = counsel US +
       exigence d'usage, à part.

COMMENT (les classes) ? — la question qui coûte de l'argent
├─ Modèle = logiciel/SaaS → 9 (logiciel) + 42 (développement/
│   mise à disposition) ; la boutique en ligne ajoute 35
├─ Modèle = produit physique → sa classe (25 vêtement,
│   3 cosmétique…) + 35 si vente au détail en propre
├─ Modèle = formation/contenu → 41 (+9 si support enregistré)
└─ Le libellé se CALIBRE sur le business réel, et on vérifie
    ROMARIN (gratuit) AVANT — une classe « large » mal
    choisie = rejet ou opposition, pas une assurance.

QUAND ? (les fenêtres qui décident)
├─ Aucune copie visible → dépôt dès que le nom est choisi
│   (la valeur du dépôt est INVERSE du moment où on le fait :
│   le plus tôt, le moins cher)
├─ Copie active / concurrent publie → FENÊTRE D'OPPOSITION
│   2 mois post-publication (art. 148.2) — URGENCE datée,
│   dossier motivé, ou l'occasion se ferme (cf. NOUR DAR :
│   même l'OMPIC répond de ses délais, art. 148-3)
└─ Marque déjà déposée → agenda : publication (veille),
    certificat, renouvellement à 10 ans (jamais raté).
```

## Le filtre des 5 questions (diagnostic M1, 15 min)

1. Quel signe porte la valeur aujourd'hui ?
2. Qui l'a créé, et quel papier le dit ?
3. Est-il déposé, sous quel numéro, dans quelles classes ?
4. Où vendez-vous, et où vendrez-vous dans 24 mois ?
5. Une fenêtre de procédure est-elle ouverte (opposition d'un tiers, votre opposition à faire) — **et jusqu'à quelle date** ?

## Les 3 faux raccourcis à démonter

| Raccourci client | Ce que l'arbre répond |
| :--- | :--- |
| « Le nom est au RC, il est protégé » | Nom commercial ≠ marque : le RC ne donne pas l'exclusivité du signe — seul l'enregistrement OMPIC le fait (classe par classe). |
| « On verra les classes quand ils nous attaquent » | La classe définit ce que vous possédez ; « vague large » = rejet, « 35 seul » = SaaS non couvert — l'erreur est commise au dépôt, pas au litige. |
| « Madrid = protection mondiale » | = protection dans les **pays désignés**, via un dépôt de base marocain, avec droit local de chaque office. Il n'existe pas de « marque mondiale ». |

## Comment lire l'arbre sans le subir

L'arbre est la colonne vertébrale de l'entretien, pas un configurateur automatique : chaque nœud renvoie à une **mission** (cession avant dépôt = M3 ; recherche avant dépôt = cœur de M2 ; fenêtre ouverte = urgence M1→opposition) — jamais à un produit panier. Sa fonction première est d'empêcher le dépôt réflexe : un client qui sort avec une cession signée et un dépôt reporté de trois semaines pour cause de titularité est mieux servi qu'un client avec un récépissé sur un signe qui ne lui appartient pas.

> Base : loi 17-97 (mod. 31-05, 23-13) — enregistrement, classes, opposition 148.2-3, renouvellement 10 ans ; loi 2-00 (mod. 34-05) — cession art. 9, preuve ; Protocole de Madrid (Maroc 08/10/1999) ; Nice (45 classes). Vérifié 29/08/2026.
