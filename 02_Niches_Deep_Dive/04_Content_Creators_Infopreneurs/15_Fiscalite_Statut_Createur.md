# 15 — Fiscalité et statut du créateur-infopreneur décortiqués

> 30k/mois = déjà hors AE sans le savoir. Mécanique statut + TVA formations + plateformes. Vérifié 07/09/2026 — AE 200k services / 500k commerce, une seule activité au RNAE (mixte prestations+boutique = inéligible), IS 20%/35%/40%, TVA 20/10/0, facturation art. 145, change 90j si clients étrangers.

## 1. Statut — pourquoi Yasmine doit basculer

80k abonnés, 30k/mois (marques 70% + boutique 30%) = ~360k/an + mixte services/commerce → double sortie de l'AE (plafond + mixité). Rester = radiation + requalification + perte charges. Voie : SARL (ou SARL-AU) avec objets distincts (prestations vs vente), comptabilité, TVA, compte pro. Simulation avec comptable : IR libératoire + CNSS T1-T8 vs IS + salaire/dividendes.

## 2. Formations en ligne — TVA et CGV

Vente de formation = vente soumise à 31-08 quand client consommateur (rétractation 7j art. 36, exceptions à ouvrir selon commencement d'exécution avec accord exprès ; remboursement 15j) + CGV (`02/14`) + facture + plateforme (Podia/Stripe : qui facture ? où est la TVA ? contrat avec la plateforme conservé). Clients UE/US : TVA/export + rapatriement 90j + registre. Sans CGV, chaque remboursement devient un chargeback gagné par l'acheteur.

## 3. Sponsoring et affiliation — encaissement propre

Contrat `14` + facture au nom de la société + paiement virement pro + déclaration. Affiliation : relevés plateforme + rapprochement bancaire mensuel. Cash/crypto sans facture = fraude + blanchiment si réinjection. Étranger qui paie sur Wise : rapatriement 90j (`08/11`).

## 4. Protocole bascule créateur (30j)

Diagnostic plafonds/mixité → SARL + RC/ICE/TP/CNSS + compte pro → avenants marques + migration boutique (CGV, 09-08, CMI) → clôture RNAE → calendrier AG + registre. Pack bascule + pack contrat marque (récurrence : 1 contrat/semaine pour le top 10%).
