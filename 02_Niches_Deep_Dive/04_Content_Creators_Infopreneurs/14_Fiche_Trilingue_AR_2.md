## TL;DR — 5 points

- **Qui :** Créateur monétisé multi-canaux (YouTube/formation/sponsors) approchant 200k CA avec emails collectés.
- **Douleur chère :** Contenu repris sans licence, marque non déposée (concurrent la dépose), 8k emails sans registre = sanction 09-08 ; AE dépassé → radiation.
- **Offre :** Pack PI Créateur + Conformité données **4 500-6 000 HT** (+ bascule SARL/SASU 5 900 si >200k) — provision 50 % art.30, TVA 20 % ou 0 % export art.92, début 7j après provision+pièces.
- **Acquisition sans pub :** scripts FR/EN/AR Darija — voir 05_Canaux / 06_Scripts (permission, pas démarchage art.31).
- **Livrable :** Dépôt marque OMPIC classes 35/41 (1 200 DH/classe, opposition tiers 2 mois) + charte licences contenu + registre 09-08 emails + CCT Mailchimp/Teachable + option création société.

## Base légale exacte

Loi 17-97 : marque 1 200 DH/classe, dépôt électronique 72h, publication BO 4-6 mois, opposition tiers 2 mois. Loi 09-08 art.14 registre dès collecte, art.43 transfert hors Maroc (Mailchimp US) via CCT. Statut : AE services <200k (IR 1 %) ; au-delà CPU (CGI art.40-I, coeff 20-30 % ≈ 2-3 % du CA) ou SARL/SASU IS 20 % LF 2026.

## Cas pratique chiffré (HT, provision 50 %)

**Avant :** Chaîne 80k abonnés sans marque déposée : un concurrent dépose le nom → rebranding 60k en pleine croissance + perte des accords sponsors.
**Après :** Pack 5 500 HT : marque déposée classes 35/41, licences sponsors standardisées, registre 09-08 + CCT Mailchimp, passage SARL préparé (J+30). Zéro exposition contrefaçon/CNDP ; marque = actif revendable.

## Erreurs qui coûtent 15k-150k

1. Sans convention art.30 avant mission -> honoraires perdus devant Bâtonnier.
2. Sans FR fait foi EN seul -> nullité juridiction Maroc.
3. Commission 10 % apporteur comptable -> sanction art.31 avertissement.
4. Contrat >10k oral -> témoignage écarté DOC art.443.
5. Pénale 30% -> réduite à 10% DOC art.264 ; réserve orale = 0 DOC art.618.
