## 3 cas chiffrés comparatifs — MRE investisseur

**Cas A — Karim MRE Paris, 40j/an Maroc, SARL Casa 100% export 500k DH CA, bénéfice 200k DH, pas de PE :**
Maroc : IS 20 % (LF 2026) = **30k DH**. France si création SASU même bénéfice : IS 25% au-delà 42,5k€ = **~45k DH** → **économie 15k DH** Maroc. Dividende 100k DH vers Paris : retenue **10% =10k** via 5000-F + devise MRE 72h vs **30k PFU** sans → **économie 20k**. Procédure : procuration apostillée (préfecture FR 15€ + Apostille Cour d'appel 14j) + statuts + RC 7-14j → SARL opérationnelle sans déplacement. Résidence : 40j <183j + foyer Paris = **non-résident** → IS source only, pas d'IR mondial MA §01.

**Cas B — Nadia MRE Bruxelles, 190j Maroc mais foyer Bruxelles, boutique e-commerce 800k DH CA Maroc :**
183j > seuil → **résidente fiscale Maroc malgré foyer BE** (CGI art.23 : 183j suffit, pas besoin foyer) → IS mondial 15% = **IS sur revenus BE non déclarés = redressement 30% pénalités**. TVA 20% due (client Maroc) = **160k DH** TVA collectée ; si elle facture client Paris → exon 0% art.92 possible uniquement si SWIFT 30j. Carte séjour 1 an obligatoire (210j >90j) **200 DH 30j** vs carte BE 2 ans 140€. **Leçon : compter cachets 365j glissants avant choix devise MRE vs convertible.**

**Cas C — Youssef MRE Madrid, SARL Casa + succursale Madrid avec salarié signataire 8 mois :**
PE caractérisé art.5/7 Conv. ES-MA 1985 → bénéfice rattaché ES **200k DH ×25% =50k IS ES** + IS Maroc sur reste 200k =40k (20 % LF 2026) → total **90k** vs **30k** sans PE (économie manquée **50k**). Dividende 80k ES → retenue **10% ES =8k** via formulaire ES 210 + crédit art.27 = 8k. Alternative sans PE (agent sans pouvoir de signer) → SARL Casa seule → total 40k + dividende 10% =48k → **économie 42k/an**. Banque : rapatriement 30j impossible si facturation ES (PE) → facturer depuis ES, pas export art.92.

## Verdict MRE / Foreign Investors

*   **Création distance** : SARL Maroc **7-14j CRI, 7 500 HT + 2 000 DH débours**, procuration apostillée 14j (Haye) + traduction assermentée ; SASU France 1 000€ 7j plus rapide mais **IS 25 % au-delà de 42,5k€ vs 20 % au Maroc (LF 2026)**.
*   **Fiscalité** : IS 20 % (LF 2026)DH (≈27k€) compétitif ; avec charges déductibles Casa (loyer 3k DH/mois vs Paris 1 200€), **bénéfice imposable réduit de 40%**. Toujours tester PE §02 avant de signer bail/salarié FR/BE/ES >6 mois.
*   **Dividende** : **10% FR / 15% BE / 10% ES** vs 30% PFU FR → **15-20k économisés /100k** via **attestation DGI résidence art.4 (30j) + formulaire 5000-F Bofip avant virement** + compte **devise MRE 72h transférable** (pas convertible). Sans 5000-F, banque FR retient 30% d'office.
*   **Compte** : MRE <183j → **devise MRE (transférable)** ; >183j → **convertible + carte 1 an 200 DH** (Loi 02-03). Erreur = blocage transfert 6 mois Office. → §01 §07 §12

## Interactions

*   §01 Résidence 183j → §09 SARL + §08 Carte : 40j = non-résident + pas de carte ; 210j = résident + carte 1 an 200 DH + IS mondial.
*   §02 PE 6m → §07 Convention art.7/27 : PE détermine où taxer → crédit art.27 réduit double imposition mais PE coûte 25% FR.
*   §03 Rapatriement 30j + §04 TVA art.92 + §12 Compte : export Paris → facture 0% + SWIFT 30j → convertible 48h ; client Maroc → TVA 20% → pas de rapatriement.
*   §10 Provision 50% + §11 DOC art.443 : convention apostillée + provision avant CRI — sinon impayé à distance + pas de preuve >10k.
*   §06 09-08 + §05 OMPIC : boutique MRE avec 09-08 registre 30j avant CMI, marque 35/9 1 200 DH/classe avant pub.

## Procédure crédit art.27 + 5000-F (détail MRE)

1. **Résidence** : compter 365j glissants (cachets) + foyer — 40j ≠ non-résident automatique si foyer Casa (§01).
2. **Apostille 14j** : procuration FR/BE → Cour d'appel + traduction assermentée 7j avant CRI 7-14j (§10 §11).
3. **Attestation DGI 30j** (art.4) : passeport + bail + RC — active Conv. 29 mai 1970/1972/1985 (§07).
4. **5000-F Bofip** : faire viser DGI Maroc, remettre à banque FR/BE/ES **avant virement** dividende → retenue **10% FR /15% BE /10% ES** vs 30% PFU → **20k économisés/100k** (Cas A) (§07).
5. **Compte devise MRE 72h** (si <183j) transférable sans plafond IGOC vs convertible 48h si >183j (§12) — choisir avant 1er rapatriement (§03).

## Lecture comparative — pourquoi comparer sans copier

SARL 10k DH CRI 7-14j avec Apostille 14j n'est pas SASU 1€ 7j France — procédure, capital libérable, RC/ICE et banque diffèrent. IS 20 % (LF 2026) <300k Maroc sur bénéfice après charges Casa (loyer 3k DH) n'est pas IS 20 % (LF 2026) <42,5k€ France sur bénéfice Paris (loyer ×4). Le 10% dividende FR n'existe que via 5000-F + attestation DGI — sans, PFU 30% automatique. Expliquez au MRE pourquoi son KBIS français ne vaut pas RC marocain et pourquoi devise MRE ≠ convertible.
