# 12 — Fiches Pratiques + Checklist (05_MRE_Foreign_Investors)

> **Niche :** MRE à Paris/Bruxelles qui crée SARL Casa à distance. Blocage = Apostille + compte MRE + dividende 10%. Sans Apostille, OMPIC refuse en 24h.

## Checklist 12 points — MRE & Investisseurs Étrangers (SARL Casa depuis l'étranger)

*   [ ] Procuration Apostille 1961 + DHL (Convention La Haye) — procuration notariée FR/BE → Apostille cour d'appel 24-48h + DHL 72h Casa, sans Apostille OMPIC/banque refuse, validité 1 an → voir Glossaire §11 (DOC preuve)
*   [ ] Attestation blocage capital 10 000 DH (Loi 5-96 SARL) — ouvrir compte pro provisoire avec RC en cours + passeport, bloquer 10k DH, attestation banque 48h, déblocage après RC définitif 7-14j → voir Glossaire §09
*   [ ] OMPIC création RC 7-14j CRI ~2 000 DH (Loi 5-96) — dossier : statuts + attestation blocage + procuration Apostille + CIN/passeport, dépôt directompic.ma, RC 7j Casa /14j hors Casa, ICE/IF auto → voir Glossaire §09
*   [ ] Compte devise MRE 72h (IGOC/BAM) — banque avec RC + passeport étranger + justificatif étranger (facture EDF), alimenté depuis l'étranger sans rapatriement 30j, transférable, 72h ouverture → voir Glossaire §12
*   [ ] Attestation résidence fiscale DGI 30j (CGI art.23) — dépôt DGI : passeport cachets + bail étranger + RC, délai 30j, indispensable pour activer convention et éviter double imposition → voir Glossaire §01
*   [ ] Convention fiscale art.27 élimination double imposition (art.4/7/27) — MRE 40j Maroc + foyer Paris = non-résident art.4 → SARL Casa taxée Maroc seul si pas PE >6m, crédit IS Maroc sur IR France art.27 économie 15k/100k → voir Glossaire §07
*   [ ] Dividende 10% France /15% Belgique (art.10 conventions) + formulaire 5000-F — retenue source Maroc 10% si MRE France (15% BE/30% sans convention), formulaire 5000-F + attestation DGI AVANT versement, virement via compte MRE → voir Glossaire §07
*   [ ] TVA art.92 exon export si clients hors Maroc (CGI art.92) — facturation export devises + rapatriement 30j → TVA 0%, sinon TVA 20% Maroc, mention art.92 + ICE sur facture art.144 → voir Glossaire §04
*   [ ] Rapatriement 30j IGOC 2024 si CA export — même si MRE non-résident, SARL Casa exportatrice doit rapatrier 30j sur compte convertible (pas MRE), SWIFT gardé 10 ans → voir Glossaire §03
*   [ ] Carte séjour non requise si <90j (Loi 02-03 art.13) — si MRE 40j/an = touriste 90j max, pas de carte ; si installation >90j → carte 1 an 200 DH préfecture 30j + bail 12 mois → voir Glossaire §08
*   [ ] Provision 50% art.30 Loi 28-08 + convention FR fait foi — convention tripartite HT/TVA signée avant procuration, provision 50% Stripe/Yousign 48h, délai 7j après provision + Apostille reçue → voir Glossaire §10
*   [ ] Registre Loi 09-08 5 colonnes si collecte clients Maroc (art.14) — dès 1 email Maroc : registre + déclaration CNDP 30j + contrat sous-traitant art.24 si hébergement AWS US art.43 → voir Glossaire §06

> **Légende :** Chaque case = Concept (base légale) — procédure 1 ligne + chiffre 2025 + renvoi Glossaire. Ne cochez pas sans avoir lu le §.

## Plan 7j — MRE Investisseur

*   **J1 :** Diag 1 200 HT — test résidence 183j + foyer + PE 6m + convention art.27 + dividende 10%
*   **J1-J2 :** Provision 50% → rédaction procuration → notaire + Apostille 48h + DHL 72h
*   **J3 :** Réception Apostille → dépôt banque blocage 10k (attestation 48h) + dépôt OMPIC directompic.ma
*   **J4-J5 :** Suivi OMPIC + corrections éventuelles dénomination, obtention RC provisoire
*   **J7 :** RC 7j + ICE/IF → ouverture compte devise MRE 72h → J14 attestation DGI 30j lancée + formulaire 5000-F préparé
*   **J14 :** Formation rapatriement 30j si export + dotation 15k si besoin SaaS
*   **J30 :** Attestation DGI + dividende 10% opérationnel, virement test via compte MRE

## Erreurs qui coûtent cher — MRE

*   Procuration FR sans Apostille → OMPIC rejet J2, 2 semaines perdues + DHL 2e envoi
*   Ouvrir compte convertible au lieu de MRE → blocage transfert dividende 10% → compte à refaire 72h
*   Verser dividende sans 5000-F → retenue 30% au lieu de 10% = 20k perdus sur 100k

## Chiffres 2025 à vérifier à chaque diag (PLF + IGOC)

*   RC OMPIC 7j Casa /14j région CRI ~2 000 DH, ICE/IF auto, compte MRE 72h
*   Résidence 183j + attestation DGI 30j, convention art.27 crédit 15k/100k

*   TVA 20% ou 0% art.92 si 3 cond., rapatriement 30j + 10 ans, carte 200 DH/30j si >90j

## Fiche comme mémoire externe, pas comme script de vente

Cette fiche est une mémoire pour ne rien rater en dossier MRE à distance : procuration sans Apostille = rejet OMPIC garanti, blocage 10k = attestation 48h avant RC, RC 7-14j CRI ~2 000 DH pas 5k, compte MRE 72h (alimenté depuis l'étranger) ≠ compte convertible (rapatriement 30j), attestation DGI 30j obligatoire avant dividende sinon retenue 30%, dividende France 10% via 5000-F (BE 15%) avant virement. Ne promettez jamais RC en 24h — 7j Casa /14j région est le délai OMPIC réel. Ordre causal : Apostille → blocage 10k → OMPIC → compte MRE → DGI 30j → dividende. Sans Apostille, rien ne démarre.
