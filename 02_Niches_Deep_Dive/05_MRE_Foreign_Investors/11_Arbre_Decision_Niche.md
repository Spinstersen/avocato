# 11 — Arbre Décision (05_MRE_Foreign_Investors)

> Réf : `00_START_HERE/03_Glossaire_12_Concepts_Cles.md` §01-§12 — MRE = résidence d'abord, tout le reste en découle.

## Ordre procédural : jours Maroc déterminent tout

<183j non-résident = IS source + dividende 10% + procuration Apostille. >183j résident = IS mondial + carte 1 an. D'où : **183j → Procuration → Compte → Dividende**.

```
[Q1] Jours physiques Maroc /365j glissants + foyer ? §01 CGI art.23
 ├─ <183j ET foyer hors MA → Non-résident → IS source seulement §01/§07
 │        └─ [Q2] Création SARL sans venir ? → Procuration Apostille ? §11 DOC art.443
 │                 ├─ NON → Procuration légalisée + Apostille + envoi DHL 72h
 │                 └─ OUI → [Q3] Compte devise MRE 72h §12 + [Q4] Dividende 10% FR §07
 └─ >183j OU foyer Casa → Résident → IS mondial 20 % (LF 2026) §09 + §01
          └─ [Q2] Carte séjour 1 an art.13 §08 ? (étranger >90j)
                   ├─ NON → Dossier préfecture 30j (bail 12m + RC + 30k/mois) §08
                   └─ OUI → Compte convertible §12 + rapatriement 30j §03 + TVA art.92 §04
```

## Tableau décision — 4 branches

| Branche | Condition | Base légale | Procédure (renvoi Glossaire) | Sortie |
|---------|-----------|-------------|------------------------------|--------|
| A — Résidence | <183j non-résident vs >183j résident | CGI art.23 §01 + Conv. art.4 §07 | Compter cachets passeport 365j + foyer → attestation DGI 30j §01/§07 → détermine IS source vs mondial | Source ou mondial |
| B — Procuration | MRE ne vient pas signer | DOC art.443 §11 + Loi 5-96 §09 | Procuration chez notaire FR/BE → Apostille (Convention Haye) → DHL Casa → dépôt OMPIC 7-14j §09 | SARL créée sans déplacement |
| C — Compte | Devise MRE vs convertible | IGOC 2024 §12 + §03 | Non-résident → compte devise MRE 72h (virement étranger) §12 ; Résident → convertible 48h + rapatriement 30j §03 | Flux conforme |
| D — Dividende | SARL Casa → MRE Paris | Conv. art.10/27 §07 | Formulaire 5000-F + attestation DGI résidence FR avant versement → retenue 10% FR /15% BE §07 → virement compte MRE §12 → crédit art.27 en FR | 10k sur 100k FR |

## Cas chiffrés

* **Karim, MRE Paris, 40j/an Casa, SARL Casa bénéfice 200k** : Non-résident §01 → IS Maroc 30k (15%) source seulement → dividende 170k → retenue 10% FR §07 =17k via 5000-F → net 153k sur compte devise MRE §12 transférable FR en 72h ; sans 5000-F retenue 15% =25,5k → **perte 8,5k**.
* **Leila, MRE Bruxelles, 210j Casa (mère malade), foyer Casa** : Résidente malgré passeport BE §01 (foyer) → IS mondial → revenus BE déclarés MA → IS 20 % (LF 2026)§09 → carte séjour non (Marocaine) mais attestation résidence MA pour éviter double impo art.27 §07 → crédit 30k.
* **Investisseur US, 20j Casa, procuration sans Apostille** : OMPIC refuse dépôt §09 → perte 14j + billet 1 200$ ; avec Apostille (45€ + 72h DHL) → SARL 7-14j OK + compte devise MRE §12.

## Erreurs / pièges

* **Piège foyer** : 40j mais épouse/enfants Casa → foyer = résident §01 → IS mondial oublié → redressement 30k + 30% pénalités.
* **Piège procuration** : Procuration légalisée mairie sans Apostille → rejet CRI → délai 7-14j passe à 30j §09/§11.
* **Piège compte** : MRE avec compte convertible (résident) au lieu de devise MRE §12 → blocage transfert dividende + contrôle Office §03.
* **Piège dividende** : Verser dividende sans 5000-F §07 → retenue 15% au lieu de 10% FR → 5k perdus/100k + régularisation 60j.
* **Piège 183j** : Compter année civile au lieu de 365j glissants §01 → 190j glissants mais 170j civils → résident quand même → IS mondial dû.
* **Piège TVA** : SARL MRE facture client Casa en EUR avec art.92 §04 → service au MA → TVA 20% redressée malgré compte MRE.
* **Piège marque** : Investisseur dépose marque perso avant SARL §05 → marque hors bilan → cession payante 15k.

## L'arbre comme outil d'entretien, pas comme automate

Pour MRE, l'arbre interdit de parler SARL ou dividende avant d'avoir tranché 183j et foyer — tout le chiffrage dividende 10%/15% §07 et compte §12 en dépend. Chaque branche renvoie à une mission avec convention provision 50% §10 et preuve DOC art.443 §11. Vérifiez CGI art.23 et convention FR-MA art.4/10/27 sgg.gov.ma à J-0.

> Diagnostic 45 min + comptable FR-MA + banque : chiffrage IS source/mondial et 5000-F à jour PLF.
