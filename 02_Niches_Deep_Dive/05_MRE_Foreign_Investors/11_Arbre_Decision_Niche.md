# 11 — Arbre Décision (05_MRE_Foreign_Investors)

> L'arbre de la niche inverse celui de toutes les autres : ici on ne demande jamais « quelle société ? » en premier. **La résidence fiscale décide, la structure exécute, la banque valide, la protection se choose avant.**

## L'arbre

```
Où est votre résidence fiscale effective (foyer/183j/
centre d'intérêts) — et puis-je le PROUVER cette année ?
├─ FLOUE (le cas de 8 clients sur 10)
│   └→ MISSION PRÉALABLE : note de statut résidentiel
│      (CGI art. 23 s. ; conv. 1970 art. 2 si France)
│      + attestation de résidence du pays prétendu.
│      Toute structure décidée avant = pari.
└─ ÉTABLIE (résident étranger / résident marocain)
    │
    ├─ L'argent de l'apport : devises traçables OU dirhams
    │   déjà au Maroc (héritage, compte local) ?
    │   ├─ Devises → régime convertibilité/rapatriement
    │   │   (IGOC 2026) : dossier d'apport monté J-0 (S4/13)
    │   └─ Dirhams → transfert futur incertain → question
    │       à trancher AVANT création (le MRE qui rentre
    │       n'a plus le même compte : pivot 10_MRE)
    │
    ├─ Activité prévue
    │   ├─ Services/tech, seul au départ
    │   │   └→ SARL-AU (loi 5-96) + clauses distance (S1/13)
    │   ├─ Plusieurs associés / investissement partagé
    │   │   └→ SARL + pacte d'associés + agrément des cessions
    │   ├─ Très petit test commercial depuis l'étranger
    │   │   └→ attendre : le AE est réservé au résident
    │   │      marocain (personne physique) — le non-résident
    │   │      n'y a pas accès : pas d'à-peu-près
    │   └─ Immobilier de gré à gré
    │       └→ détention directe vs SARL : arbitrage droits
    │           d'enregistrement + IS/IR + sortie (note M2)
    │
    ├─ La société sera-t-elle réellement DIRIGÉE du Maroc ?
    │   ├─ OUI (gérant + substance sur place) → OK
    │   └─ NON, tout depuis Paris/Bruxelles/Montréal
    │       └→ RISQUE ÉTABLISSEMENT STABLE dans le pays de
    │          direction (conv. 1970) → réorganiser pouvoirs
    │          et lieux de décision AVANT le premier contrat
    │
    └─ Angle protection (surtout investisseur étranger /
        projet moyen-gros)
        ├─ Projet ≥ 50 M DH + 50 emplois → convention
        │   d'investissement charte 03-22 (art. 9 ; clauses
        │   amiable/arbitrage art. 37-38)
        └─ En dessous → la protection = TBI de la structure
            qui investit (ouvrir le traité : FR 1996 ;
            les autres avant conseil) + contrat interne bien
            fait. JAMAIS une holding-coquille montée après.
```

## Le filtre des 5 questions (diagnostic, 2 min mental)

1. **Résidence** prouvée où, pour l'année en cours ?
2. **Apport** en devises tracées ou dirhams sur place ?
3. **Direction** effective depuis quel pays, matérialisée comment ?
4. **Structure de détention** existait-elle avant tout différend ?
5. **Sortie** prévue : qui rachète, dans quel régime de change, en combien d'années ?

Les 5 réponses s'écrivent dans la note du diagnostic — c'est le produit, pas l'enregistrement de l'entretien.

## Les 3 raccourcis mortels de la niche (à démonter en premier)

| Raccourci du client | Pourquoi c'est faux | La question de repli |
| :--- | :--- | :--- |
| « Je crée la SARL d'abord, on verra la résidence après » | La résidence change tout : étendue d'imposition, taux applicable, régime du compte, sort des dividendes | « Où avez-vous passé vos 183 derniers jours et où est votre foyer ? » |
| « Un MRE peut être AE pour tester » | L'AE (loi 114-13, CGI art. 42 s.) est un régime de **personne physique résidente au Maroc** — le non-résident n'y a pas accès (à confirmer au texte consolidé au jour du dossier) | « Qui sera résident marocain dans 12 mois : oui, non, ça dépend ? » |
| « La charte paiera 30 % de mon projet » | Dispositif principal : ≥ 50 M DH et ≥ 50 emplois (décret 2-23-1) ; les TPME passent par d'autres dispositifs instruits dossier par dossier | « Quel est le montant CAPEX réel et les emplois créés ? » |

---

## Comment lire l'arbre sans le subir

L'arbre n'est pas un automate : chaque nœud **renvoie à une mission**, jamais à une promesse. Sa seule fonction est l'ordre — résidence → origine des fonds → structure → direction → protection — parce que dans cette niche, l'erreur n° 1 n'est pas un mauvais choix mais un **choix dans le mauvais ordre** (payer la structuration juridique après la bascule résidentielle = payer deux fois ; constituer la protection après le litige = ne jamais l'avoir).

> Base : CGI art. 23 s. et art. 42 s. ; loi 5-96 ; loi-cadre 03-22 + décret 2-23-1 ; IGOC 2026 ; conv. France-Maroc 29/05/1970 ; TBI Maroc-France 1996. Vérifié 29/08/2026.
