# 03 — Carte Séjour 1 An : Procédure 30j Préfecture (art.13 Loi 02-03)

## Procédure 30j (préfecture Casa/Rabat/Marrakech)

| J | Étape | Doc |
|---|-------|-----|
| J1 | Diagnostic 1,200 HT (résidence 210j → résident) | PV diag |
| J1 | Contrat bail 12 mois légalisé (Agadir 3,000 DH/mois) + attestation banque 30k DH/mois (3 mois relevés) | Bail + banque |
| J2 | Dossier préfecture: passeport + 8 photos + bail + RC SARL (si SARL, voir `04_SARL_Nomad...`) + contrat travail/portage + taxe 200 DH + formulaire | Dossier |
| J2-30 | Récépissé 30j (légal en attendant) | Récépissé |
| J30 | Carte 1 an retirée | Carte |

## Cas Lena 210j

*   Bail Taghazout 12 mois 3,500 DH + Wise relevés 2,500€/mois → préfecture Agadir J2 → carte J30 → SARL 7j parallèle.

## Renouvellement J-30 avant expiry

*   Même dossier + attestation IS payé.

## Erreurs

*   Bail <12 mois → refus.
*   Banque <30k → refus (seuil préfecture).

## Checklist

*   [ ] Bail 12 mois légalisé
*   [ ] Banque 30k/mois 3 mois
*   [ ] RC SARL si gérant (sinon contrat portage)
*   [ ] 8 photos + taxe 200 DH
*   [ ] Récépissé 30j gardé
