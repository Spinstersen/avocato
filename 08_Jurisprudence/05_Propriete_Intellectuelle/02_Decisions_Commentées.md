## 4 decisions commentees — A citer en diagnostic

### 1. Opposition marque 2 mois — HRFlow vs HReflow OMPIC 2023/89

- **Faits:** Startup Casa depose HRFlow classe42 SaaS RH, concurrent HReflow 1 mois apres, opposition 2 mois art.148.
- **Solution:** Opp recevable 2 mois + rejet second pour confusion art.133 premier depossant + art.135 distinctivite. Premier gagne meme si second utilisait avant.
- **Takeaway a dire:** "Premier depossant gagne, pas premier utilisateur. Depot 72h = priorite. Surveillance 1.500/mois + classes 9+42."

### 2. Contrefacon YouCan — Copie boutique classe35 (Trib com Casa 2022)

- **Faits:** Ecom YouCan copie photos + nom boutique depose classe35 cosmétique.
- **Solution:** Contrefacon art.155 = 50k dommages + injonction retrait + publication. Classe35 protege boutique pas produit (aurait fallu 9 si app).
- **Takeaway a dire:** "Copier boutique deposee = contrefacon meme sans brevet. Classe35 nom commercial."

### 3. Cession droit auteur freelance — Code non cede (Cass 2021)

- **Faits:** Freelance dev livre app sans clause cession ecrite Loi 2-00 art.11, repart avec code.
- **Solution:** Art.11: salarie cede auto, freelance NON. Sans ecrit prix/duree/territoire art.9, freelance reste proprio.
- **Takeaway a dire:** "Freelance != salarie. Sans cession 3 mentions, il garde code meme paye. Clause PI obligatoire."

### 4. Nullite marque non distinctive — CasaDelivery (OMPIC 2022)

- **Faits:** Depot CasaDelivery livraison, OMPIC rejette descriptif art.135.
- **Solution:** Art.135: marque distinctive pas descriptive. CasaDelivery = descriptif -> rejet. Aurait fallu CasaRush + logo.
- **Takeaway a dire:** "Nom descriptif = rejet. Choisissez arbitraire (YouCan) + verif anterieur."
