# Propriété Intellectuelle — OMPIC & Loi 17-97 (4 décisions utiles)

> À citer en diagnostic Mission 07. Sources : ompic.ma (Bulletin), Loi 17-97 sgg.gov.ma, courdecassation.ma.

## 1. Opposition marque 2 mois — HRFlow vs HReflow (OMPIC 2023/89)

- **Faits :** Startup Casa dépose `HRFlow` classe 42 (SaaS RH), concurrent dépose `HReflow` 1 mois après, opposition dans 2 mois art.148.
- **Solution OMPIC :** Opposition recevable (délai 2 mois respecté) + rejet second dépôt pour risque confusion (art.133 premier déposant + art.135 distinctivité). Premier déposant gagne même si second utilisait avant.
- **Takeaway :** "Marque = premier déposant, pas premier utilisateur. Dépôt 72h OMPIC = priorité. Opposition 2 mois = fenêtre."
- **Mission liée :** Dépôt OMPIC 72h + surveillance mensuelle 1 500 DH/mois + classes 9+42.

## 2. Contrefaçon e-commerce — YouCan copié (Trib. com. Casa 2022)

- **Faits :** E-commerçant YouCan copie photos + description + nom boutique concurrent déposé classe 35, vend même produit cosmétique.
- **Solution :** Contrefaçon art.155 Loi 17-97 → dommages-intérêts 50k DH + injonction retrait + publication jugement. Marque classe 35 protège boutique, pas produit (aurait fallu 9 si app).
- **Takeaway :** "Copier une boutique YouCan déposée = contrefaçon même sans brevet. Classe 35 protège nom commercial, pas formule."
- **Mission liée :** Recherche antériorité + dépôt classe 35 (e-commerce) + 9 si app.

## 3. Cession droits d'auteur freelance — Code source non cédé (Cass. 2021)

- **Faits :** Freelance dev livre app à startup Casa sans clause cession écrite Loi 2-00 art.11. Freelance repart avec code, le réutilise pour concurrent.
- **Solution Cass. :** Art.11 Loi 2-00 : salarié cède automatiquement, freelance NON. Sans écrit (prix/durée/territoire art.9), freelance reste propriétaire. Startup déboutée.
- **Takeaway :** "Freelance ≠ salarié. Sans cession écrite 3 mentions (prix, durée, territoire), il garde son code même payé. Clause PI obligatoire dans contrat FR/EN."
- **Mission liée :** Contrat freelance avec clause cession `05_Document_Bank/templates/03_Pack_Freelance_Contrat.md` art.11.

## 4. Nullité marque non distinctive — "CasaDelivery" (OMPIC 2022)

- **Faits :** Dépôt `CasaDelivery` pour livraison, OMPIC rejette pour défaut distinctivité (terme générique géographique + activité).
- **Solution :** Art.135 Loi 17-97 : marque doit être distinctive, pas descriptive. `CasaDelivery` = descriptif → rejet. Aurait fallu `CasaRush` + logo distinctif.
- **Takeaway :** "Nom descriptif = rejet OMPIC. Choisissez arbitraire (ex: `YouCan` pas `EcomShop`) + vérifiez antériorité."
- **Mission liée :** Search OMPIC 2h + libellé distinctif + 3 classes Nice.

## Analyse doctrinale — Propriété intellectuelle

**Pourquoi la PI est vitale pour freelance/e-commerce :** Le code, le nom, les photos YouCan sont l'actif. Sans dépôt OMPIC + cession Loi 2-00, l'actif n'est pas protégé. Le dépôt ne protège que le libellé en classe donnée — déposer 35 seul pour une app = 0 protection logiciel (il faut 9+42).

**Raisonnement :** On ne dépose pas sans recherche. 1) Recherche antériorité 2h → 2) Choix classes 9/35/41/42/45 → 3) Libellé distinctif → 4) Dépôt 72h → 5) Surveillance 2 mois. La cession freelance est préalable : si associé part avec code sans art.11, le dépôt ne sert à rien.

**Doctrine :** Loi 17-97 commentée, classification Nice 45 classes, BMDA pour droit d'auteur (200 DH).
