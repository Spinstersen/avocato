# 07 — Droit social & CNSS : contentieux (méthode + base vérifiée)

> **Fiche de méthode.** Pas de décision inventée : base légale vérifiée + contentieux types + fiche à remplir.

## Base vérifiée

| Élément | Référence | Note |
| :--- | :--- | :--- |
| Relation de travail, lien de subordination | Code du travail, **loi 65-99** | critère central de la requalification |
| Cotisations / déclaration des salariés | Régime de sécurité sociale (CNSS) — textes consolidés `cnss.ma` | numéros d'articles à épingler au texte |
| Accident du travail | Déclaration + faute inexcusable de l'employeur (contentieux social et CNSS) | qualifier les faits avant tout chiffre |
| Auto-entrepreneur | **Loi 114-13** : pas de salariés | l'AE qui emploie = requalification |

## Contentieux types à documenter
1. **Requalification freelance / salarié** : horaires imposés, exclusivité de fait, matériel fourni, validation ligne à ligne.
2. **Accident du travail** : déclaration, faute inexcusable, indemnisation.
3. **Travail dissimulé** : procès-verbal CNSS + arriérés de cotisations + indemnités.
4. **Indemnités de rupture** : traitement social — un recours contentieux réel est pendant devant la Cour de cassation (presse spécialisée, Médias24 15/04/2026).

## Où trouver des décisions citables
- `juricaf.org` — Cour de cassation, **chambre sociale** (subordination, conventions collectives, accidents du travail).
- `cnss.ma` — textes consolidés et procédures.
- `courdecassation.ma` — décisions publiées.
- Presse économique (Médias24) — pour dater l'actualité, jamais comme précédent.
