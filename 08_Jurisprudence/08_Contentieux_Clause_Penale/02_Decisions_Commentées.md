# 02 — Decisions Commentees (08_Contentieux_Clause_Penale)

> **Version encyclopedique — 22/08/2026 — FR fait foi — Verifie sgg.gov.ma / oc.gov.ma / cndp.ma / ompic.ma**

## 4 decisions commentees — A citer en diagnostic

### 1. Clause 30% reduite 10% — Impaye freelance 50k (Cass com 2022/123)

- **Faits:** Contrat freelance 50k penalite 30% (15k) retard >30j, client paie 60j retard, freelance reclame 15k.
- **Solution:** DOC art.264 juge reduit excessive 30% ->10% (5k). Clause maintenue.
- **Takeaway a dire:** "Clause 30% = reduite 10%. Mettre 10% depart = plafond credible. Facture 30j."

### 2. Astreinte 500 DH/j — Retard livraison ecom 20j (Trib com Casa 2023)

- **Faits:** Ecom YouCan retard livraison 20j produit 300 DH, client assigne astreinte.
- **Solution:** DOC art.258 + CPC: astreinte peine/jour pour forcer exec, distincte clause penale. Juge fixe 500 DH/j apres mise en demeure 15j.
- **Takeaway a dire:** "Penale=indemnite retard 10%, astreinte=pression 500/j. Deux outils."

### 3. Reserve propriete non ecrite inopposable — Materiel 100k (Cass com 2021)

- **Faits:** Fournisseur livre 100k sans clause reserve ecrite, client ne paie pas, revendique bien.
- **Solution:** DOC art.618 reserve = transfert apres paiement complet, valide seulement si ecrite avant livraison. Orale inopposable -> creancier chirographaire dernier.
- **Takeaway a dire:** "Sans ecrit avant livraison, reserve vaut 0. Ecrivez contrat + facture avant livrer."

### 4. Cumul indemnite + penale impossible — Contrat 10%+20k (Cass com 2020)

- **Faits:** Contrat prevoit penale 10% + dommages 20k meme retard, freelance reclame deux.
- **Solution:** DOC art.264 penale = evaluation forfaitaire prejudice. Pas de cumul meme fait. Juge accorde plus eleve.
- **Takeaway a dire:** "Penale 10% OU indemnite, pas deux. Choisissez 10% forfaitaire simple."
