# 08 — Le Dopamine Board : les métriques à suivre

Ce qui n'est pas mesuré n'existe pas. Ce qui est mesuré mais invisible ne motive pas. Le Dopamine Board est un tableau Notion (ou Google Sheet) qui affiche les KPI de la flywheel de façon visible et motivante.

## 1. Le principe du Dopamine Board

Le Dopamine Board a 3 fonctions :

1. **Mesurer** : savoir où on en est.
2. **Motiver** : voir les progrès visuellement.
3. **Identifier les défaillances** : voir ce qui ne marche pas pour corriger.

> **Loi du board.** Un KPI invisible est un KPI mort. Le board doit être ouvert tous les matins.

## 2. Les KPI hebdomadaires

| KPI | Cible hebdo | Source |
| :--- | :--- | :--- |
| Posts publiés | 3/3 | LinkedIn |
| DMs et commentaires répondus | 10+/semaine | LinkedIn + email |
| Diagnostics bookés | 0-5 | Cabinet OS / Calendly |
| Missions signées | 0-2 | Cabinet OS |
| Referrals demandés | 3+ | Cabinet OS |
| Articles publiés | 1/semaine | Blog |
| Impressions LinkedIn | 5 000+ | LinkedIn analytics |
| Visites site | 200+ | Plausible/Fathom |

## 3. Les KPI mensuels

| KPI | Cible mensuelle | Source |
| :--- | :--- | :--- |
| Ateliers organisés | 1/mois | Cabinet OS |
| Partenaires identifiés | 5+ | Cabinet OS |
| Missions livrées | 1-5 | Cabinet OS |
| CA HT | objectif 35-60 k DH | Cabinet OS |
| Abonnements actifs | 2-5 | Cabinet OS |
| Referrals reçus | 3+ | Cabinet OS |

## 4. Les alertes automatiques

Alertes si le board montre :

- **Diagnostics < 2/semaine** pendant 3 semaines → problème de contenu ou lead magnet.
- **Taux conversion diagnostic → mission < 30%** → problème d'offre ou de prix.
- **CA HT mensuel < 30 k DH** pendant 2 mois → revoir la stratégie.
- **Abonnements churn > 1/mois** → problème de qualité de service.

## 6. La revue hebdomadaire (dimanche, 30 min)

Le dimanche matin, avant le batch, faire la revue :

1. Ouvrir le board.
2. Constater les écarts (objectif vs réalisé).
3. Identifier les causes.
4. Décider les actions correctives.
5. Mettre à jour les objectifs de la semaine suivante.

## 7. La revue mensuelle (1er du mois, 1h)

Le 1er du mois :

1. CA HT du mois précédent.
2. Taux de conversion (diagnostics → missions).
3. Coût d'acquisition (temps investi / mission signée).
4. Taux de churn abonnements.
5. Top 3 contenus du mois (par impressions).
6. Top 3 sources de prospects (LinkedIn, SEO, partenaires, referral).
7. Plan du mois suivant.

## 8. La revue trimestrielle (tous les 3 mois, 2h)

Tous les 3 mois :

1. CA HT cumulé.
2. Évolution des KPI.
3. Niche : persister ou pivoter ?
4. Positionnement : ajuster ?
5. Offres : ajuster ?
6. Partenaires : audit et extension.
7. Plan 90 jours suivant.

## 9. FAQ

**Q : Quel outil pour le Dopamine Board ?**
R : Notion (tableau simple), Google Sheet, ou le Cabinet OS (`webapp/`) du vault.

**Q : Le board doit-il être public ?**
R : Non, confidentiel. Visible seulement par l'avocat (et éventuellement un associé/assistant).

**Q : Que faire si je ne tiens pas la revue hebdomadaire ?**
R : Revenir au batch du dimanche en ajoutant la revue (30 min) avant la production.
