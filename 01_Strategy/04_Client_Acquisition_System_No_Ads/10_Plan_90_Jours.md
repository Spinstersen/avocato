# 10 — Plan 90 jours : déployer la flywheel

Ce fichier propose un plan 90 jours pour déployer la flywheel complète, en 4 phases de 2-3 semaines chacune.

## 1. Vue d'ensemble du plan 90 jours

```
[Phase 1 — FOUNDATION — J1-J15]
  Site + positionnement + 1er article + 1er post
        ↓
[Phase 2 — TRACTION — J16-J45]
  4 articles/mois + 12 posts/mois + 1er atelier + 1er partenaire
        ↓
[Phase 3 — SYSTEMIZE — J46-J75]
  Système quotidien en place + premiers diagnostics + 1re mission
        ↓
[Phase 4 — SCALE — J76-J90]
  Premières missions + 1er abonnement + boucle referral
```

## 2. Phase 1 — Foundation (J1-J15)

### J1-J3 — Décision et formulation

- [ ] Choisir la niche pilote (`01_Strategy/03_Unsaturated_Niches_Overview/10_Arbre_Choix_Niche.md`).
- [ ] Formuler le positionnement (`01_Strategy/02_Positioning_Trilingual_Tech_Lawyer/02_Formule_Positionnement.md`).
- [ ] Décliner en variantes (headline LinkedIn, sous-titre site, signature email).
- [ ] Saisir la commission de déontologie si besoin.

### J4-J8 — Site web et identité

- [ ] Acheter le nom de domaine.
- [ ] Configurer l'hébergement.
- [ ] Construire le site (Carrd / Notion / Hugo / Webflow).
- [ ] Rédiger l'accueil, À propos, Domaines, Contact.
- [ ] Mettre en place mentions légales + politique de confidentialité 09-08.
- [ ] Configurer Google Search Console + Plausible.
- [ ] Configurer Google Business Profile.
- [ ] Créer le wordmark logo + Canva Brand Kit.

### J9-J12 — Offres et conventions

- [ ] Définir le catalogue d'offres (3-5 packs).
- [ ] Adapter la convention-type d'honoraires.
- [ ] Mettre en place la signature électronique (Yousign).
- [ ] Préparer les templates de livrables.

### J13-J15 — Premiers contenus

- [ ] Rédiger 1er article de fond (2 000 mots).
- [ ] Publier sur le blog.
- [ ] Préparer le 1er post LinkedIn.
- [ ] Préparer le calendrier éditorial 12 semaines.

## 3. Phase 2 — Traction (J16-J45)

### J16-J30 — Production de contenu

- [ ] Publier 1 post LinkedIn/semaine.
- [ ] Publier 1 article/semaine sur le blog.
- [ ] Identifier 50 prospects cibles sur LinkedIn.
- [ ] Identifier 20 comptes à suivre.
- [ ] Préparer 1er lead magnet (PDF ou checklist).

### J31-J45 — Atelier et partenaires

- [ ] Organiser 1er atelier gratuit en coworking (J40).
- [ ] Inviter via annonce publique (pas de DM).
- [ ] Préparer une plaquette cabinet sobre.
- [ ] Contacter 1er comptable partenaire (café professionnel).
- [ ] Identifier 5 partenaires potentiels.

## 4. Phase 3 — Systemize (J46-J75)

### J46-J60 — Système quotidien

- [ ] Batch du dimanche installé (2h).
- [ ] Créneaux 11h/18h pour DMs installés.
- [ ] 3 posts/semaine réguliers.
- [ ] 1 article/semaine régulier.
- [ ] Calendly opérationnel.
- [ ] Notion de mission type prêt.

### J61-J75 — Premiers diagnostics

- [ ] 1er diagnostic booké (J65 typiquement).
- [ ] Notion de diagnostic opérationnel.
- [ ] Note de risques type prête.
- [ ] Devis + convention envoyés au 1er prospect.

## 5. Phase 4 — Scale (J76-J90)

### J76-J90 — Premières missions

- [ ] 1re mission signée (J80 typiquement).
- [ ] Notion de mission en cours.
- [ ] Loom d'introduction et de clôture.
- [ ] Facture de provision + solde envoyées.
- [ ] Demande de referral à J+3 de livraison.
- [ ] Cabinet OS alimenté (dossiers, échéances, factures).

## 6. Le suivi de plan

Tracker dans le Cabinet OS ou Notion :

- Tâches cochées par semaine.
- KPI hebdomadaires (Dopamine Board).
- Ajustements éventuels.

## 7. L'évaluation à J90

À J90, évaluer :

- 3+ diagnostics bookés → persistance.
- 1+ mission signée → réussite.
- 1+ partenaire comptable actif → réseau.
- 0 demande entrante → pivot.

## 8. La suite (J90-J180)

Si la flywheel tourne à J90, poursuivre jusqu'à J180 :

- 5-10 missions/mois.
- 2-3 abonnements.
- 2e partenaire comptable.
- 2e atelier.
- SEO mature (1 000+ visites/mois).

Voir `07_90Day_Plan/` pour le plan détaillé.

## 9. FAQ

**Q : Et si je n'ai pas fini le site à J15 ?**
R : Continuer avec un site minimal (Carrd ou Notion) et compléter après.

**Q : Et si le 1er atelier n'a que 3 inscrits ?**
R : Faire l'atelier avec 3. La régularité prime.

**Q : Et si le 1er comptable refusé ?**
R : En contacter 3 autres. Persistance.
