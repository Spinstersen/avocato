# 11 — Arbre de Décision Canal (choisir 1 canal en 3 min, pas 5)

> **Version encyclopédique — 22/08/2026 — À faire après `10_Plan_90_Jours.md`, avant `03_Acquisition`.**
> **But:** Éviter piège TDAH "je fais tout" — choisir 1 canal 90j selon ta personnalité + niche.

---

## TL;DR — 4 questions

1.  Aimes-tu écrire/design ? Oui → LinkedIn. Non → Partenariats.
2.  As-tu déjà 2 comptables chauds ? Oui → Partenariats.
3.  Aimes-tu parler en public ? Oui → Conférences CCI.
4.  As-tu petit réseau chaud ? Oui → Referral.

## Arbre complet

```
Tu dois choisir 1 canal 90j (pas 5) ?
│
├─ Aimes-tu écrire, designer sur Canva, faire carrousels ?
│   ├─ OUI (2h dimanche ok) → **LinkedIn Authority** `03_Acquisition/01`
│   │   Routine: 3 posts/sem + 10 com/j + DM permission
│   │   Niche fit: Freelance, Creators, 09-08
│   │   Langue: FR + EN posts, AR comments si besoin
│   └─ NON → continue
│
├─ Détestes-tu les réseaux / préfères relation 1-1 ?
│   ├─ OUI → **Partenariats Comptables** `03_Acquisition/03`
│   │   Routine: 5 msg/sem + 1 atelier CCI/mois
│   │   Niche fit: 09-08, Ecom, MRE, AE→SARL
│   │   AR Darija roi (téléphone)
│   └─ NON → continue
│
├─ Aimes-tu parler / animer (même stressé) ?
│   ├─ OUI → **Conférences/Ateliers 60 min** `03_Acquisition/05`
│   │   Routine: 1 atelier CCI/mois + 10% conversion diagnostic
│   │   Langue: FR + vulgarisation AR Darija
│   └─ NON → continue
│
├─ As-tu déjà 3 clients / 5 contacts chauds ?
│   ├─ OUI → **Referral Engine** `03_Acquisition/06`
│   │   Routine: demande recommandation après livraison `06_Referral_Engine/01_Le_Moment`
│   │   Script sobre AR/FR
│   └─ NON → continue
│
├─ As-tu une boutique/atelier lieu physique ?
│   ├─ OUI → **SEO + Google Business** `03_Acquisition/02`
│   │   Routine: 2 articles/mois long-tail + fiche GMB
│   └─ NON → **WhatsApp Community** `03_Acquisition/04`
│       Routine: lead magnet → WA → diagnostic
│
└─ Choisi → Bloque 90j (`07_Systeme_Quotidien_30min:05-20`): Lun 10h 3 MITs, Dim batch, Ven review.
    └─ Évalue J90 `08_Metrics_Dopamine_Board`: diagnostics/semaine, packs, CA. Si <2 diag/sem → pivot canal.
```

## Checklist 1 min — Canal valide ?

- [ ] Je peux tenir 30 min/jour 90j ?
- [ ] Ma niche y traîne (FB Groups vs CCI vs LinkedIn) ?
- [ ] Langue fit (LinkedIn EN vs Partenariats AR) ?
- [ ] Déonto sobre (information, pas pitch) `01_Rules/11` ?
