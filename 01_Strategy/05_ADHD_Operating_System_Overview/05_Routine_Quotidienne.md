# 05 — La routine quotidienne

Ce fichier détaille la routine quotidienne type d'un avocat ADHD — version complète (1h30) et version minimum viable (45 min).

## 1. Le matin — Cadrage (15 min)

### 7h30-7h45 — Routine de cadrage

- [ ] Ouvrir Notion Dashboard.
- [ ] Identifier les 3 MITs du jour.
- [ ] Consulter le calendrier (créneaux du jour).
- [ ] Vérifier le Cabinet OS (échéances, dossiers en retard).
- [ ] Note d'intention : « Aujourd'hui je vais [3 MITs] ».

Pas d'email, pas de LinkedIn, pas de WhatsApp avant ce cadrage.

## 2. Le matin — Production (60-90 min)

### 8h-9h30 — Bloc de production n°1

- [ ] 3 pomodoros de 25 min sur la tâche de production n°1 (article, mission, atelier).
- [ ] 5 min de pause entre chaque pomodoro.
- [ ] Body double si possible (Focusmate, coworking).

Pas d'email, pas de notifications.

## 3. Le matin — Batch DMs n°1 (15 min)

### 11h-11h15 — Batch DMs et emails

- [ ] Répondre aux 3-5 messages prioritaires.
- [ ] Supprimer les emails non pertinents.
- [ ] Marquer les emails à traiter plus tard.

Pas plus de 15 min. Le reste attendra le créneau de 18h.

## 4. L'après-midi — Mission juridique ou visio (90 min)

### 14h-15h30 — Bloc de mission ou visio

- [ ] Visio diagnostic (si programmée).
- [ ] Rédaction de contrat, audit, etc.
- [ ] Suivi de mission en cours.

## 5. L'après-midi — Batch DMs n°2 (15 min)

### 18h-18h15 — Batch DMs et emails

- [ ] Répondre aux messages accumulés depuis 11h.
- [ ] Programmation des publications du lendemain si besoin.

## 6. Le soir — Revue (5 min)

### 19h-19h05 — Revue du jour

- [ ] Cocher les cases des MITs accomplies dans Notion.
- [ ] Marquer la case « streak » (1 post publié aujourd'hui ?).
- [ ] Identifier les 1-2 MITs à reporter au lendemain.
- [ ] Fermer Notion et le Cabinet OS.

## 7. Le jour minimum viable (45 min)

Les jours bas (fatigue, mauvaise nuit, charge mentale) :

- [ ] 10 min : répondre à 3 DMs prioritaires.
- [ ] 20 min : rédiger un brouillon de post LinkedIn (avec prompt IA).
- [ ] 15 min : 1 message à un comptable ou partenaire potentiel.

Total : 45 min. Streak maintenu. Pas de culpabilité.

## 8. Le jour off sacré

Un jour par semaine (samedi ou dimanche après-midi) :

- Pas de réseaux sociaux.
- Pas d'email.
- Pas de travail.
- Déconnexion totale.

Ce jour est non négociable. Il prévient le burnout.

## 9. Le calendrier-type hebdomadaire

```
LUNDI : Production + DMs + visio (si)
MARDI : Production + DMs + mission juridique
MERCREDI : Production + atelier (1x/mois) + DMs
JEUDI : Mission juridique + production + DMs
VENDREDI : Production (vidéo) + revue hebdo + DMs
SAMEDI : OFF
DIMANCHE : Batch contenu (10h-12h) + préparation semaine
```

## 10. La règle des 2 créneaux email

- 11h : batch n°1.
- 18h : batch n°2.

Hors de ces créneaux, pas de consultation des messages. Cela préserve l'énergie et la concentration.

## 11. La règle des 3 MITs

Chaque matin, 3 MITs (Most Important Tasks) :

1. Une tâche de production (article, mission, atelier).
2. Une tâche de relation (DM, partenaire, client).
3. Une tâche d'acquisition (post, lead magnet, atelier).

Ne pas passer aux autres tâches tant que les 3 MITs ne sont pas faites.

## 12. FAQ

**Q : Que faire si je suis à 100% en audience le matin ?**
R : Adapter le calendrier. Production le soir si possible. Sinon, journée minimum viable le jour d'audience.

**Q : Puis-je sauter le batch du dimanche ?**
R : Possible, mais la semaine est plus chargée. Préférable de tenir le batch.

**Q : Le jour off est-il obligatoire ?**
R : Oui. Non négociable. Le respect de ce jour préserve la santé mentale.
