# 10 — Fiches pratiques prêtes à l'emploi

Ce fichier rassemble les outils prêts à l'emploi : checklists, prompts IA, scripts de langage, modèles-type.

## 1. La checklist quotidienne

- [ ] 7h30-7h45 : Cadrage (3 MITs dans Notion).
- [ ] 8h-9h30 : Production (3 pomodoros).
- [ ] 11h-11h15 : Batch DMs n°1.
- [ ] 14h-15h30 : Mission ou visio.
- [ ] 18h-18h15 : Batch DMs n°2.
- [ ] 19h-19h05 : Revue du jour (cocher cases).

## 2. La checklist hebdomadaire

- [ ] Lundi : Publication post LinkedIn long form.
- [ ] Mercredi : Publication carrousel.
- [ ] Vendredi : Publication vidéo courte.
- [ ] Vendredi 14h-14h30 : Revue hebdo.
- [ ] Dimanche 10h-12h : Batch contenu semaine suivante.

## 3. La checklist mensuelle

- [ ] 1er du mois : Revue mensuelle (1h).
- [ ] 1er du mois : CA HT du mois précédent.
- [ ] 1er du mois : Plan du mois suivant.
- [ ] Tous les 3 mois : Revue trimestrielle.

## 4. Le prompt IA pour générer un post LinkedIn

```
Tu es un avocat d'affaires trilingue au Maroc, spécialisé en
[freelance offshore / e-commerce / conformité 09-08].

Rédige un post LinkedIn long form (200-400 mots) sur le sujet
suivant : [sujet précis].

Format :
- Ton analytique, pas promotionnel.
- Pas de comparaison avec un confrère.
- Pas de CTA commercial.
- Pas de promesse de résultat.
- Signature sobre à la fin.
```

## 5. Le prompt IA pour résumer une jurisprudence

```
Tu es un assistant juridique. Résume la jurisprudence suivante
en 200 mots maximum, en identifiant :
1. Les faits
2. La question de droit
3. La décision
4. La portée pour la pratique

Texte à résumer : [texte intégral]
```

## 6. Le prompt IA pour reformuler un article

```
Reformule l'article suivant dans un style plus lisible et
engageant, sans perdre la précision juridique. Garde les
références aux articles de loi. Structure avec des titres H2.

Article : [texte]
```

## 7. Le prompt IA pour générer un carrousel Canva

```
Transforme l'article suivant en un carrousel Canva de 8 slides
(format 1080×1080).

Structure :
- Slide 1 : Titre accrocheur
- Slides 2-7 : Points clés (1 idée par slide)
- Slide 8 : Call-to-action sobre (lien site)

Article : [texte]
```

## 8. Le modèle-type de réponse à un prospect entrant

```
Bonjour [nom],

Merci pour votre message. Pour bien comprendre votre situation
et vous proposer une mission adaptée, je vous propose un
diagnostic de [45 minutes] à [600-900] DH HT (convention
d'honoraires écrite conformément à l'article 30 de la Loi 28-08).

À l'issue, je vous remets une note de risques écrite et un
devis pour la mission à mener. La provision est de [50]%
du montant.

Pour réserver le créneau, vous pouvez [lien Calendly] ou me
renvoyer ce email avec vos disponibilités.

Bien à vous,

[Nom Prénom]
Avocat au barreau de [Ville]
```

## 9. Le modèle-type de relance (J+7)

```
Bonjour [nom],

Je me permets de revenir vers vous suite à notre échange du
[date] et au devis envoyé le [date]. Avez-vous eu l'occasion
de le consulter ?

Je reste à votre disposition pour toute question ou
ajustement.

Bien à vous,

[Nom]
```

## 10. Le modèle-type de demande de referral

```
Bonjour [nom],

J'espère que la mission [type] vous convient. Si vous avez
2 minutes, je vous serais reconnaissant de me dire ce qui
vous a plu le plus. Cela m'aide à améliorer mon offre.

Par ailleurs, si vous connaissez 1-2 autres [freelances/
e-commerçants] qui ont le même type de problème, je peux
leur envoyer la même checklist gratuitement. Vous me mettez
en contact WhatsApp ou par email ?

Pour chaque recommandation, j'offre un diagnostic gratuit
(valeur 600-900 DH HT) au filleul.

Bien à vous,

[Nom]
```

## 11. Le modèle-type de refus poli

```
Bonjour [nom],

Merci pour votre message. Votre demande relève d'un domaine
qui sort de mon champ d'intervention (droit des affaires,
conformité numérique, freelance offshore, e-commerce, MRE
investisseur).

Je vous recommande de vous adresser à un confrère spécialisé.
Vous pouvez consulter l'annuaire du barreau de [Ville] à
[lien].

Bien à vous,

[Nom]
```

## 12. La checklist de lancement de mission

- [ ] Convention d'honoraires envoyée par Yousign.
- [ ] Paiement de la provision 50% reçu.
- [ ] Notion de mission créé et partagé avec le client.
- [ ] Loom d'introduction 3 min envoyé.
- [ ] Calendrier de mission planifié.

## 13. La checklist de livraison de mission

- [ ] Tous les livrables produits.
- [ ] Notion de mission à jour.
- [ ] restitution de clôture 10-15 min enregistré.
- [ ] PDF design soigné généré.
- [ ] Email de livraison envoyé.
- [ ] Facture de solde envoyée (Yousign).

## 14. La checklist post-mission

- [ ] J+3 : email de demande de feedback + referral.
- [ ] J+15 : relance si pas de réponse.
- [ ] J+30 : check-in.
- [ ] J+90 : email + proposition d'abonnement.

## 15. FAQ

**Q : Les prompts IA sont-ils à adapter ?**
R : Oui, à personnaliser selon la niche et le sujet. Toujours valider le contenu généré.

**Q : Les modèles-type sont-ils conformes déontologiquement ?**
R : Oui, sous réserve de personnalisation et de respect du RIO local. Vérifier avec la commission de déontologie si doute.
