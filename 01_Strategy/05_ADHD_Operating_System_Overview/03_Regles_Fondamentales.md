# 03 — Les 4 règles fondamentales du système ADHD-avocat

Ce fichier détaille les 4 règles pivot du système : externaliser, timeboxer, dopaminer, réduire la friction. Chaque règle est expliquée avec ses applications concrètes.

## Règle 1 — Externaliser tout (ne pas garder en tête)

### Principe

Le cerveau ADHD a une mémoire de travail altérée. Ce qui n'est pas écrit est oublié ou encombrant. Toute tâche, idée, contact, document doit être **externalisé** dans un système.

### Applications

- **Second brain** : Notion ou Obsidian (voir `04_Second_Brain_Notion.md`). Toutes les tâches, idées, infos client, modèles, contenus en cours.
- **Calendrier** : tous les créneaux timeboxés (Google Calendar, Cal.com).
- **Whiteboard physique** au bureau : 3 colonnes TODO / DOING / DONE. Max 3 tâches en DOING.
- **Carnet de poche** pour capturer les idées en mobilité (synchronisé avec Notion le soir).
- **Voice notes** : pour rédiger à voix haute (Whisper, Notion AI) puis transcrire.

### Le test

Si une tâche est dans votre tête et pas dans Notion, c'est une faille. Si une info client est dans votre tête et pas dans le Cabinet OS, c'est un risque.

## Règle 2 — Timeboxer, ne pas task-lister

### Principe

La todo list est une suggestion ; le calendrier est la loi. Toute tâche doit être assignée à un **créneau horaire précis** dans le calendrier.

### Applications

- ❌ « Travailler sur le site » (tâche ouverte).
- ✅ « Mardi 10h-11h30 — Construire la page d'accueil Carrd (3 pomodoros 25 min) ».

### Le calendrier-type

```
LUNDI
  9h-9h30    : Planification de la semaine (3 MITs)
  10h-11h30  : Production (article, mission, atelier)
  11h-11h15  : Batch DMs et emails
  14h-15h    : Visio diagnostic (si programmée)
  18h-18h15  : Batch DMs et emails

MARDI
  10h-11h    : Production
  11h-11h15  : Batch DMs
  14h-15h    : Mission juridique (rédaction contrat)
  18h-18h15  : Batch DMs

MERCREDI
  10h-11h    : Production
  11h-11h15  : Batch DMs
  14h-15h    : Atelier en coworking (1x/mois) ou visio
  18h-18h15  : Batch DMs

JEUDI
  10h-11h    : Mission juridique
  11h-11h15  : Batch DMs
  14h-15h    : Production
  18h-18h15  : Batch DMs

VENDREDI
  10h-11h    : Production (vidéo hebdo)
  11h-11h15  : Batch DMs
  14h-15h    : Revue hebdo (30 min) + planification
  18h        : Fin de semaine

SAMEDI : OFF (sacré)

DIMANCHE
  10h-12h    : Batch de contenu (3 posts de la semaine)
```

## Règle 3 — Dopaminer à dessein

### Principe

Le cerveau ADHD fonctionne à la dopamine. Il faut donc **structurer les récompenses** plutôt que les attendre.

### Applications

- **Micro-victoires** : checklist avec cases à cocher (voir `07_90Day_Plan/05_Daily_Checklist_Template.md`). Chaque case cochée = dopamine.
- **Body double** : travailler en présentiel ou en visio muette (Focusmate, study-with-me YouTube).
- **Récompense** : après 3 pomodoros, 15 min de pause (marche, thé, musique). Pas après une journée entière.
- **Visual streak** : habit tracker imprimé, marquer X chaque jour où un post est publié. Ne pas casser la chaîne.
- **Célébration des jalons** : 1ère mission signée, 5e mission, 1er abonnement, 1er referral.

### Le menu dopamine

À préparer à l'avance pour ne pas tomber dans le doom scrolling :

| Action accomplie | Récompense |
| :--- | :--- |
| 1 pomodoro (25 min) | Pause 5 min, marche |
| 3 pomodoros | Pause 15 min, café, musique |
| 1 article livré | Sortie 30 min |
| 1 post publié | Thé ou chocolat |
| 1 diagnostic booké | Déjeuner avec body double |
| 1 mission signée | Dîner festif |
| 5 missions/mois | Weekend off |
| 10 missions/mois | Voyage court |

## Règle 4 — Réduire la friction au démarrage

### Principe

Le démarrage d'une tâche est le moment le plus difficile pour le cerveau ADHD. Réduire la friction au démarrage augmente les chances de finir la tâche.

### Applications

- **Templates > page blanche** : tous les packs et templates dans `05_Document_Bank/templates/`. Pas de création from scratch.
- **Règle des 5 minutes** : « Je vais juste ouvrir Notion et écrire le titre ». Souvent on continue.
- **Environnement contrôlé** :
  - Téléphone dans une autre pièce.
  - Application Freedom ou Cold Turkey pour bloquer réseaux sociaux.
  - Porte du bureau fermée.
  - Musique instrumentale (lo-fi, binaural beats).
- **Préparation la veille** : ouvrir Notion la veille avec le template prêt, pour que le matin on arrive directement dans la production.

### La friction inversée

Pour réduire la friction des bonnes actions, **l'augmenter pour les mauvaises** :

- Téléphone dans une autre pièce = friction pour checker Instagram.
- Notifications coupées = friction pour checker les emails.
- Comptes déconnectés = friction pour ouvrir LinkedIn par réflexe.

## FAQ

**Q : Combien de temps pour installer les 4 règles ?**
R : 4-6 semaines pour les transformer en réflexe. Persistance nécessaire.

**Q : Que faire si une règle ne tient pas ?**
R : Identifier pourquoi. Souvent, c'est la friction qui est trop élevée (ex : Notion mal structuré). Ajuster l'outil, pas la règle.

**Q : Les règles s'appliquent-elles au travail juridique classique ?**
R : Oui. La rédaction d'actes, l'audit, la plaidoirie bénéficient du timeboxing et de la friction réduite.
